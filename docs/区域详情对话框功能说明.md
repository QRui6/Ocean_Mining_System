# 区域详情对话框功能说明

## 功能概述

区域详情对话框提供了区域监控的详细信息，包括：
1. **区域内船舶** - 显示所有在区域内的船舶详细信息
2. **事件日志** - 显示所有事件（船舶进入/离开/预警），按时间排序

## 使用方法

### 1. 打开对话框
在区域监控面板中，点击任意区域卡片即可打开该区域的详情对话框。

### 2. 查看船舶信息
点击对话框顶部的 **"区域内船舶"** 卡片（显示船舶数量），下方会展示所有船舶的详细信息。

#### 船舶信息包括：

**基本信息**
- 船舶中文名称 / 英文名称
- MMSI（海上移动业务识别码）
- IMO（国际海事组织编号）
- 呼号（Call Sign）
- 风险等级（安全/中风险/高风险）

**船舶参数**
- 船舶类型（渔船、货船、油轮等）
- 船长（米）
- 船宽（米）
- 吃水（米）
- 航速（节）
- 航向（度）
- 船首向（度）

**位置信息**
- 当前经纬度坐标（精确到6位小数）
- 目的港
- 预计到达时间（ETA）

**气象条件**
- 当前位置的风速（m/s）
- 当前位置的浪高（m）
- 温度（°C）
- 风速/浪高超过阈值时会用红色标注

**时间信息**
- 进入区域时间
- 最后更新时间

### 3. 查看事件日志
点击对话框顶部的 **"预警数量"** 卡片，下方会切换到事件日志视图。

#### 事件类型：

**🚢 船舶进入事件**（蓝色）
- 显示船舶名称
- 进入时的位置坐标
- 进入时的航速
- 进入时的气象条件（风速、浪高）

**🚢 船舶离开事件**（绿色）
- 显示船舶MMSI
- 离开时间

**⚠️ 气象预警事件**（红色）
- 预警消息（风速超标/浪高超标）
- 严重程度（严重/高级/中级/低级）
- 气象数据（风速、浪高）
- 是否已解决

#### 事件统计：
对话框顶部显示事件统计标签：
- 红色标签：预警数量
- 蓝色标签：进入事件数量
- 绿色标签：离开事件数量

## 数据来源

### 船舶信息
- 从数据库 `area_ships` 表获取基本信息
- 通过船讯网API实时获取最新的船舶详细信息
- 包括船舶参数、位置、航行状态等

### 事件日志
- 从数据库 `event_logs` 表获取船舶进入/离开事件
- 从数据库 `warnings` 表获取预警事件
- 合并后按时间倒序排列（最新的在最上面）

## 视觉设计

### 风险等级标识
- **✓ 安全**（绿色）：气象条件正常
- **⚡ 中风险**（橙色）：风速或浪高接近阈值
- **⚠️ 高风险**（红色）：风速或浪高超过阈值

### 船舶卡片颜色
- 高风险船舶：红色边框 + 红色背景
- 中风险船舶：橙色边框 + 橙色背景
- 安全船舶：灰色边框 + 白色背景

### 事件卡片样式
- 预警事件：左侧红色边框 + 红色背景
- 进入事件：左侧蓝色边框 + 蓝色背景
- 离开事件：左侧绿色边框 + 绿色背景

## 实时更新

- 对话框打开时自动加载最新数据
- 数据通过后端API实时获取
- 船舶信息通过船讯网API获取最新状态
- 事件日志默认显示最近50条记录

## API接口

### 获取区域船舶
```
GET /api/areas/:id/ships
```
返回区域内所有船舶的详细信息（包括船讯网API数据）

### 获取事件日志
```
GET /api/areas/:id/events?limit=50
```
返回区域的事件日志（包括船舶进入/离开和预警事件）

## 注意事项

1. **数据加载时间**：由于需要调用船讯网API获取每艘船的详细信息，加载时间可能较长（取决于区域内船舶数量）

2. **API限制**：船讯网API有调用频率限制，大量船舶时可能会有延迟

3. **气象数据**：气象数据来自船舶进入时或定时更新时获取的数据，可能不是实时的

4. **事件数量**：默认显示最近50条事件，可以通过API参数调整
