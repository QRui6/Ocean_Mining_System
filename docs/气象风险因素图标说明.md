# 气象风险因素图标功能说明

## 功能概述

在航线气象节点上显示具体的风险因素标识，让用户一眼就能看出是什么原因导致的风险等级变化。

## 风险因素标识

当气象节点的风险等级为"注意"、"警告"或"危险"时，会在节点序号旁边显示相应的风险因素标识：

| 标识 | 含义 | 触发条件 |
|------|------|----------|
| **W** | Wind（风速） | 风速超过注意阈值 |
| **H** | Wave Height（浪高） | 浪高超过注意阈值 |
| **V** | Visibility（能见度） | 能见度低于注意阈值 |
| **S** | Swell（涌高） | 涌高超过注意阈值 |
| **C** | Current（海流） | 海流超过注意阈值 |

## 显示规则

1. **安全等级**（绿色）：不显示任何风险因素标识
2. **注意等级**（黄色）：显示所有超过"注意"阈值的因素
3. **警告等级**（橙色）：显示所有超过"注意"阈值的因素
4. **危险等级**（红色）：显示所有超过"注意"阈值的因素

## 示例

```
节点显示示例：
- "1" - 安全，无风险因素
- "2 W" - 风速超标
- "3 W H" - 风速和浪高都超标
- "4 W H V" - 风速、浪高、能见度都超标
- "5 W H V S C" - 所有因素都超标
```

## 阈值配置

风险因素的判定基于当前的阈值设置：

### 默认阈值
- **风速**：注意 10 m/s，警告 15 m/s，危险 20 m/s
- **浪高**：注意 2 m，警告 3 m，危险 4 m
- **能见度**：注意 5000 m，警告 2000 m，危险 1000 m
- **涌高**：注意 2 m，警告 3 m，危险 4 m
- **海流**：注意 1 m/s，警告 2 m/s，危险 3 m/s

### 自定义阈值
用户可以在"高级设置"中调整阈值，风险因素标识会自动根据新阈值更新。

## 技术实现

### 核心函数

```javascript
/**
 * 分析风险因素，返回超标项目的标识
 * @param {Object} weather - 气象数据
 * @param {Object} risk - 风险评估结果
 * @returns {Array} 风险因素标识数组，如 ['W', 'H', 'V']
 */
analyzeRiskFactors(weather, risk) {
    const factors = [];
    
    // 只在非安全等级时显示风险因素
    if (risk.level === 'safe') {
        return factors;
    }
    
    // 检查各项指标是否超标
    // ...
    
    return factors;
}
```

### 渲染逻辑

在 `renderWeatherVisualization()` 函数中：

```javascript
// 分析风险因素
const riskFactors = this.analyzeRiskFactors(weather, risk);

// 在标签中显示序号和风险因素
label: {
    text: String(i + 1) + (riskFactors.length > 0 ? ' ' + riskFactors.join(' ') : ''),
    // ...
}
```

## 用户体验

1. **直观性**：用户无需点击节点就能快速识别风险来源
2. **简洁性**：使用单字母标识，不占用过多空间
3. **一致性**：标识与详情面板中的气象数据对应
4. **响应性**：阈值调整后，标识会自动更新
