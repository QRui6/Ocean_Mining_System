# 风场图层测试清单

```bash
npm run dev
```

## 预期效果

### 视觉效果
- 流动的粒子从西向东移动（模拟西风带）
- 赤道附近粒子较慢（无风带）
- 粒子颜色根据风速变化：
  - 青色：低速（0-5 m/s）
  - 绿色：中低速（5-10 m/s）
  - 黄色：中速（10-15 m/s）
  - 橙色：中高速（15-20 m/s）
  - 红色：高速（>20 m/s）

### 性能指标
- 初始加载时间：< 2 秒
- 帧率：> 30 FPS
- 内存占用：< 200 MB

## 常见问题

### Q1: 风场不显示
**检查**:
1. 浏览器控制台是否有错误
2. 网络请求是否成功
3. 尝试刷新页面

### Q2: 粒子太少或太多
**调整**:
在 `MapContainer.vue` 中修改 `particlesTextureSize`:
```javascript
particlesTextureSize: 64,  // 减少粒子
particlesTextureSize: 256, // 增加粒子
```

### Q3: 粒子移动太快或太慢
**调整**:
在 `MapContainer.vue` 中修改 `speedFactor`:
```javascript
speedFactor: 0.5,  // 减慢速度
speedFactor: 1.5,  // 加快速度
```

### Q4: 颜色不明显
**调整**:
在 `MapContainer.vue` 中修改 `colors` 和 `lineWidth`:
```javascript
lineWidth: 5.0,  // 增加线宽
colors: ['#0000ff', '#00ff00', '#ffff00', '#ff0000'], // 更鲜艳的颜色
```
