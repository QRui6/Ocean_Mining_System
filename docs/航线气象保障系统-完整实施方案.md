## 二、数据需求分析

### 2.1 气象数据需求

#### 风场数据 (Wind Field)

**数据源**：NOAA GFS (Global Forecast System)
- 官网：https://nomads.ncep.noaa.gov/
- 格式：GRIB2
- 分辨率：0.25° × 0.25° (约 25km)
- 更新频率：每 6 小时
- 预报时长：未来 10 天
- 参数：
  - U 分量 (UGRD) - 东西向风速
  - V 分量 (VGRD) - 南北向风速
  - 高度：10m 地面风

**转换后格式 (JSON)**：
```json
{
  "header": {
    "refTime": "2024-01-01T00:00:00Z",
    "forecastTime": "2024-01-01T06:00:00Z",
    "nx": 1440,
    "ny": 721,
    "dx": 0.25,
    "dy": 0.25,
    "lo1": 0,
    "la1": 90,
    "lo2": 359.75,
    "la2": -90
  },
  "data": [
    {"u": 5.2, "v": -3.1},  // 每个网格点
    ...
  ]
}
```

**文件大小**：
- 原始 GRIB2：约 50 MB
- 转换后 JSON：约 20 MB
- 压缩后 (gzip)：约 2 MB

#### 波浪数据 (Wave)

**数据源**：NOAA WaveWatch III
- 官网：https://polar.ncep.noaa.gov/waves/
- 格式：GRIB2
- 分辨率：0.5° × 0.5°
- 更新频率：每 6 小时
- 参数：
  - 有效波高 (HTSGW)
  - 波浪周期 (PERPW)
  - 波浪方向 (DIRPW)

**转换后格式**：
```json
{
  "header": {...},
  "data": [
    {
      "height": 2.5,      // 波高 (米)
      "period": 8.0,      // 周期 (秒)
      "direction": 270    // 方向 (度)
    },
    ...
  ]
}
```

#### 洋流数据 (Ocean Current)

**数据源**：HYCOM (Hybrid Coordinate Ocean Model)
- 官网：https://www.hycom.org/
- 格式：NetCDF
- 分辨率：1/12° (约 8km)
- 更新频率：每天
- 参数：
  - U 分量 (水平速度)
  - V 分量 (垂直速度)
  - 深度：表层 (0m)

**转换后格式**：
```json
{
  "header": {...},
  "data": [
    {
      "u": 0.5,    // 东西向流速 (m/s)
      "v": -0.3    // 南北向流速 (m/s)
    },
    ...
  ]
}
```
