# 地图选点标记修复说明

## 问题描述

在添加避让点和途经点功能后，点击"选点"按钮在地图上选择位置时，所有类型的点都显示终点的图标（红色标记），这是不正确的。

## 问题原因

`MapContainer.vue` 中的 `handlePickPoint` 函数没有区分不同类型的选点，也没有为避让点和途经点创建相应的标记。

## 修复方案

### 1. 扩展选点类型支持

在 `handlePickPoint` 函数中添加对以下类型的支持：
- `start`: 起点（绿色，标记 A）
- `end`: 终点（红色，标记 B）
- `avoid`: 避让点（橙色，标记 ×）
- `through`: 途经点（蓝色，标记 ●）

### 2. 创建不同颜色的标记

根据选点类型创建不同颜色和标签的地图标记：

| 类型 | 颜色 | 标记符号 | 标签文字 |
|------|------|----------|----------|
| start | 绿色 (#22c55e) | A | 起点 |
| end | 红色 (#ef4444) | B | 终点 |
| avoid | 橙色 (#f97316) | × | 避让点 |
| through | 蓝色 (#3b82f6) | ● | 途经点 |

### 3. 添加坐标修正

由于界面使用了 CSS 缩放，需要修正点击坐标：

```javascript
const baseWidth = 1920;
const baseHeight = 1080;
const scaleX = window.innerWidth / baseWidth;
const scaleY = window.innerHeight / baseHeight;

const correctedPosition = new Cesium.Cartesian2(
    click.position.x / scaleX,
    click.position.y / scaleY
);
```

### 4. 临时显示标记

标记会在选点后显示2秒，然后自动移除，让用户确认选择的位置。

## 修改的代码

### MapContainer.vue

```javascript
// 地图选点状态
let pickPointCallback = null;
let pickPointHandler = null;
let pickPointType = null; // 当前选点类型
let pickPointMarkerEntity = null; // 当前选点标记

// 处理地图选点请求
const handlePickPoint = (data) => {
    // ... 取消选点逻辑
    
    // 保存回调函数和类型
    pickPointCallback = data.callback;
    pickPointType = data.type;
    
    // ... 创建点击处理器
    
    pickPointHandler.setInputAction((click) => {
        // 修正坐标
        const correctedPosition = new Cesium.Cartesian2(
            click.position.x / scaleX,
            click.position.y / scaleY
        );
        
        // 获取经纬度
        const cartesian = viewer.camera.pickEllipsoid(correctedPosition, ...);
        
        // 根据类型创建不同的标记
        let markerColor, markerLabel, markerText;
        
        switch (pickPointType) {
            case 'start':
                markerColor = '#22c55e';
                markerLabel = '起点';
                markerText = 'A';
                break;
            case 'end':
                markerColor = '#ef4444';
                markerLabel = '终点';
                markerText = 'B';
                break;
            case 'avoid':
                markerColor = '#f97316';
                markerLabel = '避让点';
                markerText = '×';
                break;
            case 'through':
                markerColor = '#3b82f6';
                markerLabel = '途经点';
                markerText = '●';
                break;
        }
        
        // 创建标记
        pickPointMarkerEntity = viewer.entities.add({
            position: Cesium.Cartesian3.fromDegrees(lng, lat),
            billboard: { ... },
            label: { ... }
        });
        
        // 调用回调
        if (pickPointCallback) {
            pickPointCallback(lng, lat);
        }
        
        // 2秒后移除标记
        setTimeout(() => {
            if (pickPointMarkerEntity && viewer) {
                viewer.entities.remove(pickPointMarkerEntity);
                pickPointMarkerEntity = null;
            }
        }, 2000);
    });
};
```

## 测试步骤

1. **测试起点选择**
   - 在点到点模式下，点击起点的"地图选点"
   - 在地图上点击一个位置
   - 应该看到绿色标记，标签显示"起点"，符号为 A
   - 2秒后标记自动消失

2. **测试终点选择**
   - 点击终点的"地图选点"
   - 在地图上点击一个位置
   - 应该看到红色标记，标签显示"终点"，符号为 B

3. **测试避让点选择**
   - 展开"航线高级配置"
   - 添加一个避让点
   - 点击"选点"按钮
   - 在地图上点击一个位置
   - 应该看到橙色标记，标签显示"避让点"，符号为 ×

4. **测试途经点选择**
   - 添加一个途经点
   - 点击"选点"按钮
   - 在地图上点击一个位置
   - 应该看到蓝色标记，标签显示"途经点"，符号为 ●

5. **测试取消选点**
   - 点击任意"选点"按钮
   - 再次点击同一个"选点"按钮（取消）
   - 应该没有任何标记出现

## 注意事项

1. 标记会在2秒后自动消失，避免地图上标记过多
2. 每次只能选择一个点，选择新点时会移除旧标记
3. 取消选点时会立即移除标记
4. 坐标已经过修正，适配了界面的CSS缩放
