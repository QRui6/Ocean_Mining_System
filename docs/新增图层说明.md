# 新增图层说明

## 灾害预警图层新增项

在图层控制面板的"灾害预警"分类下，新增了以下三个子图层：

### 1. 极端海洋环境

**ID**: `extreme_ocean`  
**默认状态**: 关闭

**功能说明**：
- 监测和预警极端海洋环境条件
- 包括：
  - 极端波高（有效波高 > 7 米）
  - 极端海流（流速 > 2 m/s）
  - 异常海温（偏离正常值 ±3°C）
  - 极端盐度变化

**可视化方式**：
- 热力图：显示极端海洋环境的分布区域
- 颜色编码：
  - 🟡 黄色：轻度极端（预警）
  - 🟠 橙色：中度极端（警告）
  - 🔴 红色：重度极端（危险）

**数据来源**：
- NOAA GFS 海洋模型
- HYCOM 全球海洋预报系统
- 实时浮标观测数据

---

### 2. 极端大气环境

**ID**: `extreme_atmosphere`  
**默认状态**: 关闭

**功能说明**：
- 监测和预警极端大气环境条件
- 包括：
  - 极端风速（风速 > 20 m/s，相当于 8 级风）
  - 极端气压（气压 < 980 hPa 或 > 1030 hPa）
  - 极端降水（降水量 > 50 mm/h）
  - 极端能见度（能见度 < 1 km）

**可视化方式**：
- 粒子系统：显示极端风场的流动
- 等值线：显示气压异常区域
- 颜色编码：
  - 🟡 黄色：轻度极端（预警）
  - 🟠 橙色：中度极端（警告）
  - 🔴 红色：重度极端（危险）

**数据来源**：
- NOAA GFS 大气模型
- ECMWF 欧洲中期天气预报
- 气象卫星观测数据

---

### 3. 内波

**ID**: `internal_wave`  
**默认状态**: 关闭

**功能说明**：
- 监测和预警海洋内波现象
- 内波是海洋内部密度层之间的波动，对深海作业有重要影响
- 包括：
  - 内波振幅（垂直位移）
  - 内波周期
  - 内波传播方向
  - 内波影响深度

**可视化方式**：
- 3D 剖面图：显示内波的垂直结构
- 动画：显示内波的传播过程
- 颜色编码：
  - 🔵 蓝色：弱内波（振幅 < 10 米）
  - 🟢 绿色：中等内波（振幅 10-30 米）
  - 🟡 黄色：强内波（振幅 30-50 米）
  - 🔴 红色：极强内波（振幅 > 50 米）

**数据来源**：
- HYCOM 海洋模型
- 卫星遥感数据（SAR）
- 海洋浮标观测
- 声学多普勒流速剖面仪（ADCP）

**对深海采矿的影响**：
- 内波可能导致采矿设备的垂直位移
- 影响采矿管道的稳定性
- 影响水下机器人的操作精度

## 使用方法

### 1. 打开图层控制面板

在左侧面板中，点击"图层控制"标题展开面板。

### 2. 展开灾害预警分类

点击"灾害预警"行，展开子图层列表。

### 3. 启用新增图层

点击对应图层右侧的开关按钮，启用或关闭图层：
- 极端海洋环境
- 极端大气环境
- 内波

### 4. 查看可视化效果

启用图层后，地图上会显示对应的可视化效果。

```javascript
    // ...
  }

    this.data = data;
    this.render();
  }
  
  render() {
    // 使用粒子系统渲染极端风场
    // ...
  }
}

// 内波
class InternalWaveLayer {
  constructor(viewer, data) {
    this.viewer = viewer;
    this.data = data;
    this.render();
  }
  
  render() {
    // 使用 3D 剖面图渲染内波
    // ...
  }
}
```

## 注意事项

1. **数据更新频率**：
   - 极端海洋环境：每 6 小时更新
   - 极端大气环境：每 6 小时更新
   - 内波：每 12 小时更新

2. **数据存储**：
   - 保留最近 7 天的数据
   - 历史数据归档到数据库

3. **性能考虑**：
   - 使用 WebGL 加速渲染
   - 使用 Web Worker 处理数据
   - 使用 LOD（细节层次）优化

4. **用户体验**：
   - 提供图层透明度调节
   - 提供颜色方案切换
   - 提供数据导出功能
