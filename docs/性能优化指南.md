# 性能优化指南

## 🐌 卡顿原因分析

### 1. Cesium 渲染性能
- **问题**：默认每帧都渲染，消耗大量 GPU
- **解决**：已启用按需渲染 `requestRenderMode: true`

### 2. GeoJSON 数据量
- **当前**：2.8MB，约包含多个矿区多边形
- **影响**：加载和渲染需要时间

### 3. CSS 动画效果
- **问题**：毛玻璃效果 `backdrop-filter` 性能消耗大
- **影响**：左侧面板、头部等多处使用

### 4. 时间更新
- **问题**：每秒更新可能触发 Vue 重渲染
- **影响**：较小，但可优化

## ✅ 已实施的优化

### Cesium 性能优化
```javascript
{
    requestRenderMode: true,  // 按需渲染
    maximumRenderTimeChange: Infinity,  // 减少不必要渲染
    contextOptions: {
        webgl: {
            powerPreference: 'high-performance'  // 使用高性能GPU
        }
    }
}
```

## 🚀 进一步优化建议

### 1. 减少毛玻璃效果
如果卡顿严重，可以减少 `backdrop-filter` 使用：

**src/styles/components.css**
```css
.tech-panel-enhanced {
    backdrop-filter: blur(8px);  /* 从 12px 降到 8px */
}
```

或完全禁用：
```css
.tech-panel-enhanced {
    backdrop-filter: none;
    background: rgba(15, 23, 42, 0.95);  /* 增加不透明度补偿 */
}
```

### 2. 简化 GeoJSON 数据
如果矿区数量很多，可以简化几何体：

**使用 mapshaper 工具**
```bash
npm install -g mapshaper
mapshaper ocean_mining_final.geojson -simplify 10% -o ocean_mining_simplified.geojson
```

### 3. 延迟加载数据
不在初始化时立即加载，而是等地图加载完成后：

```javascript
viewer.camera.flyTo({
    destination: Cesium.Cartesian3.fromDegrees(-140.0, 10.0, 15000000),
    duration: 2
}).then(() => {
    // 飞行完成后再加载数据
    loadMiningData();
});
```

### 4. 使用 LOD（细节层次）
根据相机距离显示不同详细程度：

```javascript
entities.forEach(entity => {
    entity.polygon.distanceDisplayCondition = new Cesium.DistanceDisplayCondition(
        0,  // 最小距离
        50000000  // 最大距离，超过此距离不显示
    );
});
```

### 5. 禁用不必要的动画
**src/styles/components.css**
```css
/* 禁用过渡动画 */
* {
    transition: none !important;
    animation: none !important;
}
```

### 6. 减少 DOM 更新
使用 `v-memo` 或 `v-once` 指令：

```vue
<div v-memo="[time.getMinutes()]">
    <!-- 只在分钟变化时更新 -->
    {{ formatTime(time) }}
</div>
```

## 📊 性能监控

### 1. 查看 FPS
打开浏览器开发者工具 → Performance → 录制

### 2. Cesium 性能统计
```javascript
viewer.scene.debugShowFramesPerSecond = true;
```

### 3. 检查渲染次数
```javascript
let renderCount = 0;
viewer.scene.postRender.addEventListener(() => {
    renderCount++;
    console.log('渲染次数:', renderCount);
});
```

## 🎯 推荐配置

### 低端设备
```javascript
{
    requestRenderMode: true,
    maximumRenderTimeChange: Infinity,
    // 降低分辨率
    resolutionScale: 0.8,
    // 禁用光照
    globe: {
        enableLighting: false
    }
}
```

### 高端设备
```javascript
{
    requestRenderMode: false,  // 每帧渲染，更流畅
    maximumRenderTimeChange: 0.0,
    // 抗锯齿
    msaaSamples: 4
}
```

## 🔧 快速诊断

### 检查是否是数据问题
暂时注释掉数据加载：
```javascript
// loadMiningData();  // 注释这行
```

如果不卡了，说明是数据渲染问题。

### 检查是否是CSS问题
暂时禁用毛玻璃：
```css
.tech-panel-enhanced {
    backdrop-filter: none !important;
}
```

如果不卡了，说明是CSS性能问题。

## 💡 最佳实践

1. **按需加载** - 只加载可见区域的数据
2. **数据分层** - 将数据分成多个图层，按需显示
3. **使用 WebWorker** - 在后台线程处理数据
4. **缓存结果** - 避免重复计算
5. **虚拟滚动** - 左侧面板使用虚拟列表
