# 点击坐标修正方案说明

## 问题分析

### 根本原因
App.vue 使用了 CSS `transform: scale()` 来缩放整个应用容器，导致点击坐标与 Cesium 坐标系不匹配。

### 问题详解

1. **容器缩放**
   ```javascript
   // App.vue
   const containerStyle = computed(() => ({
       transform: `scale(${scale.value.x}, ${scale.value.y})`,
       width: `${baseWidth}px`,  // 固定 1920px
       height: `${baseHeight}px`  // 固定 1080px
   }));
   ```

2. **坐标不匹配**
   - 用户在屏幕上点击 (x, y)
   - Cesium 接收到的坐标是相对于 1920x1080 容器的
   - 但容器被 CSS scale 缩放了
   - 导致 `viewer.scene.pick()` 拾取位置偏差

3. **示例**
   ```
   屏幕分辨率: 1366x768
   缩放比例: scaleX = 1366/1920 ≈ 0.71, scaleY = 768/1080 ≈ 0.71
   
   用户点击屏幕坐标: (683, 384)
   Cesium 接收到: (683, 384)
   实际应该是: (683/0.71, 384/0.71) ≈ (962, 541)
   
   偏差: 约 279px!
   ```

## 解决方案

### 方案 1：坐标修正（已实施）⭐

在点击事件中，将屏幕坐标转换为 Cesium canvas 的实际坐标。

#### 实施步骤

1. **计算缩放比例**
   ```javascript
   const baseWidth = 1920;
   const baseHeight = 1080;
   const scaleX = window.innerWidth / baseWidth;
   const scaleY = window.innerHeight / baseHeight;
   ```

2. **修正点击坐标**
   ```javascript
   const correctedPosition = new Cesium.Cartesian2(
       click.position.x / scaleX,
       click.position.y / scaleY
   );
   ```

3. **使用修正后的坐标拾取**
   ```javascript
   const pickedObject = viewer.scene.pick(correctedPosition);
   ```

4. **信息面板位置**
   - 面板位置使用原始点击坐标（因为面板在缩放后的容器中）
   - 不需要修正

#### 代码实现

```javascript
handler.setInputAction((click) => {
    // 计算缩放比例
    const scaleX = window.innerWidth / 1920;
    const scaleY = window.innerHeight / 1080;
    
    // 修正坐标
    const correctedPosition = new Cesium.Cartesian2(
        click.position.x / scaleX,
        click.position.y / scaleY
    );
    
    // 使用修正后的坐标拾取
    const pickedObject = viewer.scene.pick(correctedPosition);
    
    if (Cesium.defined(pickedObject) && pickedObject.id) {
        // 处理点击...
    }
}, Cesium.ScreenSpaceEventType.LEFT_CLICK);
```

## 其他可选方案

### 方案 2：移除 CSS 缩放

完全移除 CSS scale，改用响应式布局：

**优点：**
- 彻底解决坐标问题
- 更好的性能

**缺点：**
- 需要重新调整所有组件
- 工作量大

### 方案 3：使用原生事件

直接监听 canvas 的原生事件：

```javascript
viewer.scene.canvas.addEventListener('click', (event) => {
    const rect = viewer.scene.canvas.getBoundingClientRect();
    const x = event.clientX - rect.left;
    const y = event.clientY - rect.top;
    
    const pickedObject = viewer.scene.pick(new Cesium.Cartesian2(x, y));
});
```

**优点：**
- 绕过 Cesium 事件系统

**缺点：**
- 仍需处理 CSS scale
- 失去 Cesium 便利性

## 注意事项

1. ✅ 缩放比例与 App.vue 保持一致（1920x1080）
2. ✅ 信息面板位置使用原始坐标
3. ✅ 添加了详细的调试日志
4. ✅ 同时支持 2D 和 3D 模式
5. ✅ 窗口大小改变时自动重新计算

## 性能影响

- 每次点击时计算缩放比例：**可忽略**（简单除法运算）
- 创建新的 Cartesian2 对象：**可忽略**（轻量级对象）
- 总体性能影响：**几乎为零**

## 总结

方案 1 是最简单、最有效的解决方案，通过简单的坐标转换就能完全解决点击偏差问题，无需修改现有的布局结构。
