# 气象节点优化说明

## 优化目标

让气象节点清晰可见且可点击，移除复杂的风险因素标识，保持界面简洁。

## 优化内容

### 1. 节点显示优化

**增大节点大小**
- 从 10px 增加到 18px
- 更容易看到和点击

**提高颜色饱和度**
- 透明度从 0.8 提高到 0.95
- 颜色更鲜明，风险等级一目了然

**加粗边框**
- 从 2px 增加到 3px
- 白色边框更清晰

**提高节点高度**
- 从 0m 提高到 100m
- 避免被地形遮挡

### 2. 标签优化

**增大字体**
- 从 16px 增加到 20px
- 序号更清晰可读

**添加背景色**
- 背景色与节点颜色一致（透明度 40%）
- 序号更容易识别

**增加内边距**
- 背景内边距 8x6 像素
- 标签更美观

### 3. 距离缩放

**节点缩放**
- 近距离（< 1000m）：放大 1.5 倍
- 远距离（> 5000km）：缩小到 0.5 倍

**标签缩放**
- 近距离（< 1000m）：放大 1.2 倍
- 远距离（> 5000km）：缩小到 0.5 倍

## 风险等级颜色

| 风险等级 | 颜色 | 说明 |
|---------|------|------|
| 安全 | 🟢 #2ECC71 | 绿色，气象条件良好 |
| 注意 | 🟡 #F1C40F | 黄色，需要注意 |
| 警告 | 🟠 #F39C12 | 橙色，建议谨慎 |
| 危险 | 🔴 #E74C3C | 红色，不建议航行 |

## 点击功能

### 点击节点查看详情

1. 点击地图上的气象节点
2. 弹出气象详情窗口
3. 显示完整的气象数据：
   - 数据时间
   - 风速、风向
   - 浪高、涌浪
   - 能见度
   - 气温、气压

### 详情窗口内容

```
标题：风险等级描述
━━━━━━━━━━━━━━━━━━━━━━
数据时间：2024-12-19 20:00:00
风速：7.6 m/s
风向：175.3°
浪高：0.4 m
涌浪高：0.4 m
涌浪方向：143°
能见度：24135.2 m
气温：16.6 °C
气压：1018 hPa
```

## 使用方法

### 1. 规划航线
- 在航线规划面板输入起点和终点
- 点击"规划航线"按钮

### 2. 分析气象
- 点击"分析气象"按钮
- 等待气象数据加载

### 3. 查看节点
- 地图上显示带序号的气象节点
- 节点颜色表示风险等级
- 序号表示航线顺序

### 4. 查看详情
- 点击任意节点
- 查看详细气象数据
- 点击窗口外部关闭

## 技术实现

### 节点渲染代码

```javascript
const entity = this.viewer.entities.add({
    id: `weather_marker_${i}`,
    position: Cesium.Cartesian3.fromDegrees(point.lng, point.lat, 100),
    point: {
        pixelSize: 18,
        color: Cesium.Color.fromCssColorString(risk.color).withAlpha(0.95),
        outlineColor: Cesium.Color.WHITE,
        outlineWidth: 3,
        heightReference: Cesium.HeightReference.RELATIVE_TO_GROUND,
        disableDepthTestDistance: Number.POSITIVE_INFINITY,
        scaleByDistance: new Cesium.NearFarScalar(1000, 1.5, 5000000, 0.5)
    },
    label: {
        text: String(i + 1),
        font: '20px bold sans-serif',
        fillColor: Cesium.Color.WHITE,
        outlineColor: Cesium.Color.BLACK,
        outlineWidth: 4,
        style: Cesium.LabelStyle.FILL_AND_OUTLINE,
        pixelOffset: new Cesium.Cartesian2(0, 25),
        verticalOrigin: Cesium.VerticalOrigin.TOP,
        heightReference: Cesium.HeightReference.RELATIVE_TO_GROUND,
        disableDepthTestDistance: Number.POSITIVE_INFINITY,
        scaleByDistance: new Cesium.NearFarScalar(1000, 1.2, 5000000, 0.5),
        backgroundColor: Cesium.Color.fromCssColorString(risk.color).withAlpha(0.4),
        backgroundPadding: new Cesium.Cartesian2(8, 6),
        showBackground: true
    }
});

// 存储数据用于点击
entity._weatherData = weather;
entity._riskData = risk;
entity._segmentData = data;
```

### 点击事件处理

```javascript
// MapContainer.vue 中的点击事件
if (entity.id && entity.id.startsWith('weather_marker_')) {
    const weatherData = {
        weather: entity._weatherData,
        risk: entity._riskData
    };
    
    const details = routeWeatherLayer.showWeatherDetails(weatherData);
    selectedWeather.value = details;
}
```
