# 深海采矿气象预报系统 - 启动指南

## ✅ 已修复的问题

1. **添加了 Vue 插件** - 在 vite.config.ts 中添加了 `@vitejs/plugin-vue`
2. **更新了依赖** - 在 package.json 中添加了缺失的 Vue 插件依赖
3. **简化了 HTML** - 移除了不必要的 CDN 引用和重复的入口文件
4. **修复了 main.js** - 改用标准的 Vite + Vue 3 方式，移除了 vue3-sfc-loader
5. **删除了重复文件** - 移除了所有 .js 版本的组件文件，只保留 .vue 文件
6. **安装了依赖** - 已执行 npm install

## 🚀 启动步骤

### 1. 配置 API Key（可选）
如果需要使用 Gemini API，请编辑 `.env.local` 文件：
```bash
GEMINI_API_KEY=你的实际API密钥
```

### 2. 启动开发服务器
```bash
npm run dev
```

### 3. 访问应用
打开浏览器访问：`http://localhost:3000`

## 📦 其他命令

- **构建生产版本**：`npm run build`
- **预览生产版本**：`npm run preview`

## 🔧 技术栈

- Vue 3 - 前端框架
- Vite - 构建工具
- Cesium - 3D 地球可视化
- Tailwind CSS - 样式框架（通过 CDN）
- 天地图 - 地图服务

## 📝 注意事项

- 项目使用天地图服务，Token 已在代码中配置
- Cesium 通过 CDN 引入，首次加载可能较慢
- 默认端口为 3000，可在 vite.config.ts 中修改
