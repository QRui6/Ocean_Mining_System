## 三、数据库配置

### 3.1 PostgreSQL

```bash
# 切换到 postgres 用户
sudo -u postgres psql

# 创建数据库
CREATE DATABASE weather_system;

# 创建用户
CREATE USER weather_user WITH PASSWORD 'your_password';

# 授权
GRANT ALL PRIVILEGES ON DATABASE weather_system TO weather_user;

# 启用 PostGIS
\c weather_system
CREATE EXTENSION postgis;

# 退出
\q
```

### 3.2 Redis

```bash
# 编辑配置
sudo nano /etc/redis/redis.conf

# 修改以下配置
bind 127.0.0.1
maxmemory 2gb
maxmemory-policy allkeys-lru

# 重启 Redis
sudo systemctl restart redis
```

## 四、后端部署

### 4.1 项目部署

```bash
# 创建项目目录
mkdir -p /var/www/weather-system
cd /var/www/weather-system

# 克隆代码 (或上传)
git clone your-repo-url backend
cd backend

# 安装依赖
npm install --production

# 创建环境变量
cat > .env << EOF
NODE_ENV=production
PORT=3000

# 数据库
DB_HOST=localhost
DB_PORT=5432
DB_NAME=weather_system
DB_USER=weather_user
DB_PASSWORD=your_password

# Redis
REDIS_HOST=localhost
REDIS_PORT=6379

# API Keys
MARINETRAFFIC_API_KEY=your_api_key
NOAA_API_KEY=your_api_key

# 数据目录
DATA_DIR=/var/www/weather-system/data
EOF

# 创建数据目录
mkdir -p /var/www/weather-system/data/weather/{wind,wave,current}

# 运行数据库迁移
npm run migrate

# 测试启动
npm start
```

### 4.2 使用 PM2 管理进程

```bash
# 安装 PM2
npm install -g pm2

# 启动应用
pm2 start src/app.js --name weather-api

# 设置开机自启
pm2 startup
pm2 save

# 查看日志
pm2 logs weather-api

# 监控
pm2 monit
```

## 五、前端部署

### 5.1 构建前端

```bash
# 在本地构建
cd frontend
npm install
npm run build

# 上传 dist 目录到服务器
scp -r dist/* user@server:/var/www/weather-system/frontend/
```

### 5.2 Nginx 配置

```bash
# 创建配置文件
sudo nano /etc/nginx/sites-available/weather-system

# 添加以下内容
server {
    listen 80;
    server_name your-domain.com;
    
    # 前端
    location / {
        root /var/www/weather-system/frontend;
        try_files $uri $uri/ /index.html;
        
        # 启用 gzip
        gzip on;
        gzip_types text/plain text/css application/json application/javascript;
    }
    
    # 后端 API
    location /api {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
    
    # WebSocket
    location /ws {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "Upgrade";
        proxy_set_header Host $host;
    }
    
    # 静态气象数据
    location /data {
        alias /var/www/weather-system/data;
        
        # 启用 gzip
        gzip on;
        gzip_types application/json;
        
        # 缓存
        expires 30m;
        add_header Cache-Control "public, immutable";
    }
}

# 启用站点
sudo ln -s /etc/nginx/sites-available/weather-system /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
```

### 5.3 SSL 证书 (Let's Encrypt)

# 获取证书

## 八、备份策略

### 8.1 数据库备份

```bash
# 创建备份脚本
cat > /var/www/weather-system/backup-db.sh << 'EOF'
#!/bin/bash
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR=/var/backups/weather-system
mkdir -p $BACKUP_DIR

# 备份数据库
pg_dump -U weather_user weather_system | gzip > $BACKUP_DIR/db_$DATE.sql.gz

# 删除 7 天前的备份
find $BACKUP_DIR -name "db_*.sql.gz" -mtime +7 -delete

echo "数据库备份完成: $DATE"
EOF

chmod +x /var/www/weather-system/backup-db.sh

# 添加到 crontab (每天凌晨 3 点)
0 3 * * * /var/www/weather-system/backup-db.sh
```

### 8.2 数据文件备份

```bash
# 备份到阿里云 OSS (可选)
# 安装 ossutil
wget http://gosspublic.alicdn.com/ossutil/1.7.15/ossutil64

sudo mv ossutil64 /usr/local/bin/ossutil

# 配置
ossutil config

# 同步数据
ossutil sync /var/www/weather-system/data oss://your-bucket/data/
```

## 九、安全配置

### 9.1 防火墙

```bash
# 安装 ufw
sudo apt install -y ufw

# 允许 SSH
sudo ufw allow 22/tcp

# 允许 HTTP/HTTPS
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# 启用防火墙
sudo ufw enable

# 查看状态
sudo ufw status
```

### 9.2 SSH 安全

```bash
# 编辑 SSH 配置
sudo nano /etc/ssh/sshd_config

# 修改以下配置
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes

# 重启 SSH
sudo systemctl restart sshd
```

## 十一、故障排查

### 常见问题

**1. 后端无法启动**
```bash
# 查看日志
pm2 logs weather-api

# 检查端口占用
sudo lsof -i :3000

# 检查数据库连接
psql -U weather_user -d weather_system -h localhost
```

**2. 前端无法访问**
```bash
# 检查 Nginx 状态
sudo systemctl status nginx

# 查看 Nginx 日志
sudo tail -f /var/log/nginx/error.log

# 测试配置
sudo nginx -t
```

**3. 气象数据更新失败**
```bash
# 查看更新日志
tail -f /var/log/weather-update.log

# 手动运行更新
cd /var/www/weather-system/backend
node scripts/update-weather.js
```
