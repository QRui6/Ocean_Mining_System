# 点到点航线规划使用说明

## 功能概述

系统现在支持两种航线规划模式：
1. **港到港模式**：输入港口代码（如 CNSHA、JPYOK）进行规划
2. **点到点模式**：通过地图选点或手动输入坐标进行规划

## 使用步骤

### 方式一：地图选点（推荐）

1. 点击右侧工具栏的"航线规划"按钮
2. 在航线规划面板中，选择"点到点"模式
3. 点击"起始点"下方的"地图选点"按钮
4. 在地图上点击选择起点位置（按钮会变成绿色并闪烁）
5. 点击"结束点"下方的"地图选点"按钮
6. 在地图上点击选择终点位置（按钮会变成红色并闪烁）
7. 点击"规划路径"按钮

### 方式二：手动输入坐标

1. 点击右侧工具栏的"航线规划"按钮
2. 在航线规划面板中，选择"点到点"模式
3. 在"起始点"输入框中输入经度和纬度
   - 例如：经度 121.5, 纬度 31.2
4. 在"结束点"输入框中输入经度和纬度
   - 例如：经度 139.7, 纬度 35.7
5. 点击"规划路径"按钮

## 功能特点

- ✅ 支持地图可视化选点，直观方便
- ✅ 支持手动输入精确坐标
- ✅ 自动修正CSS缩放导致的坐标偏差
- ✅ 选点时按钮会高亮显示当前状态
- ✅ 规划完成后可进行航线气象分析

## 技术实现

### 事件流程

```
ShipTrackingPanel (点击"地图选点")
    ↓ emit('pickPoint', { type: 'start'/'end' })
App.vue (handlePickPoint)
    ↓ 设置 pickingPointType
MapContainer (watch pickingPointType)
    ↓ 创建点击处理器
用户点击地图
    ↓ emit('pointPicked', lng, lat)
App.vue (handlePointPicked)
    ↓ 调用 shipTrackingRef.setPickedPoint()
ShipTrackingPanel (setPickedPoint)
    ↓ 更新坐标输入框
```

### 坐标修正

由于界面使用了CSS缩放（scale），需要修正点击坐标：

```javascript
const baseWidth = 1920;
const baseHeight = 1080;
const scaleX = window.innerWidth / baseWidth;
const scaleY = window.innerHeight / baseHeight;

const correctedPosition = new Cesium.Cartesian2(
    click.position.x / scaleX,
    click.position.y / scaleY
);
```

## API接口

点到点航线规划使用船讯网API：

```
GET /PlanRouteByPoint?key={API_KEY}&start_point={lng,lat}&end_point={lng,lat}
```

参数格式：
- `start_point`: "121.5,31.2" (经度,纬度)
- `end_point`: "139.7,35.7" (经度,纬度)

## 注意事项

1. 坐标格式为：经度在前，纬度在后
2. 经度范围：-180 到 180
3. 纬度范围：-90 到 90
4. 选点时会自动取消之前的选点状态
5. 可以随时点击"地图选点"按钮取消选点模式
