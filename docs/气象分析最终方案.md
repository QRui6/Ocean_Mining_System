# 航线气象分析 - 最终方案

## 核心改进

### 不再采样，使用所有航线点

**之前的方案**：
- 每50海里采样一个点
- 只获取采样点的气象数据
- 导致数据点少，线段有偏差

**最终方案**：
- 直接使用规划航线上的所有点
- 为每个点获取气象数据
- 气象线段完全沿着原始航线

## 工作流程

### 1. 航线规划
用户输入起点和终点 → API返回航线（例如100个点）

### 2. 计算到达时间
```javascript
let cumulativeDistance = 0;
route.map((point, index) => {
    if (index > 0) {
        const distance = calculateDistance(route[index - 1], point);
        cumulativeDistance += distance;
    }
    
    const hoursFromStart = cumulativeDistance / shipSpeed;
    const arrivalTime = new Date(startTime.getTime() + hoursFromStart * 3600000);
    
    return { ...point, arrivalTime, distanceFromStart };
});
```

### 3. 获取气象数据
为每个点调用气象API：
```javascript
// 第一个点：当前气象
result = await getWeatherByPoint(point.lng, point.lat);

// 其他点：预测气象
const weatherTime = Math.floor(arrivalTime.getTime() / 1000);
result = await getWeatherByPoint(point.lng, point.lat, weatherTime);
```

### 4. 计算风险等级
```javascript
const risk = calculateRiskLevel(weatherData);
// 返回：{ level: 'safe'|'caution'|'warning'|'danger', color: '#00FF00' }
```

### 5. 渲染彩色线段
按风险等级分段，合并相同颜色的连续段：
```javascript
// 示例：100个点，风险等级变化
点1-30:  绿色 (safe)
点31-60: 黄色 (caution)
点61-80: 橙色 (warning)

// 渲染4条线段

线段4: 点81-100 (红色)
```

## 性能优化

### 1. 合并相同颜色段
不是为每两个点创建一条线段，而是合并连续的相同颜色段：
- 100个点 → 可能只需要4-10条线段
- 减少渲染实体数量
- 提高性能

### 2. 并发请求
所有气象API请求并发执行：
```javascript
const weatherPromises = routeWithTime.map(async (point) => {
    return await getWeatherByPoint(point.lng, point.lat, weatherTime);
});
const results = await Promise.all(weatherPromises);
```

### 3. 数据清理
自动过滤无效数据（-32767等特殊值）：
```javascript
cleanWeatherData(data) {
    Object.keys(data).forEach(key => {
        if (typeof data[key] === 'number' && data[key] < -30000) {
            data[key] = 0;
        }
    });
}
```

## 优势

1. **完美对齐**：气象线段完全沿着原始航线，无偏差
2. **数据完整**：每个航线点都有气象数据
3. **时间准确**：基于船速和距离计算每个点的到达时间
4. **颜色鲜明**：纯色线段（绿/黄/橙/红），风险等级一目了然
5. **性能优化**：合并相同颜色段，减少渲染实体

## 注意事项

1. **API调用次数**：航线点数越多，API调用越多（例如100个点 = 100次调用）
2. **加载时间**：并发请求，但仍需等待所有请求完成
3. **数据有效性**：API返回的未来预报数据可能包含无效值，已自动清理
4. **刷新频率**：建议每6-12小时刷新一次气象数据
