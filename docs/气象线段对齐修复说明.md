# 气象线段对齐修复说明

## 问题描述

气象线段（绿色粗线）与原始航线（紫色细线）有明显偏差，不重合。

## 问题原因

### 原来的实现
1. 原始航线有很多密集的航点（例如100个点）
2. 气象分析时每50海里采样一个点（例如只有10个采样点）
3. 气象线段直接连接这些采样点
4. 结果：气象线段走直线，原始航线可能有弯曲

### 示意图
```
原始航线：  A---B---C---D---E---F---G---H---I---J
采样点：    A-----------D-----------G-----------J
气象线段：  A===========D===========G===========J  (直线连接)
```

## 解决方案

### 新的实现
1. 保存完整的原始航线（所有点）
2. 为原始航线的每个点分配气象数据（基于最近的采样点）
3. 按风险等级分段，合并相同颜色的连续段
4. 结果：气象线段完全沿着原始航线绘制

### 示意图
```
原始航线：  A---B---C---D---E---F---G---H---I---J
采样点：    A-----------D-----------G-----------J
气象数据：  绿  绿  绿  绿  黄  黄  黄  红  红  红
气象线段：  A===B===C===D===E===F===G===H===I===J  (沿原始航线)
           └─绿色段─┘└─黄色段─┘└─红色段─┘
```

## 技术实现

### 1. 保存原始航线
```javascript
async analyzeRoute(route, options = {}, onProgress) {
    // 保存完整的原始航线
    this.originalRoute = route;
    
    // 采样点（每50海里一个点）
    const samples = sampleRoutePoints(route, 50);
}
```

### 2. 为每个点分配气象数据
```javascript
const routeWithWeather = this.originalRoute.map((routePoint) => {
    // 找到最近的采样点
    let nearestSample = this.weatherData[0];
    let minDistance = this.calculatePointDistance(routePoint, nearestSample.point);
    
    for (let i = 1; i < this.weatherData.length; i++) {
        const distance = this.calculatePointDistance(routePoint, this.weatherData[i].point);
        if (distance < minDistance) {
            minDistance = distance;
            nearestSample = this.weatherData[i];
        }
    }
    
    return {
        point: routePoint,
        risk: nearestSample.risk
    };
});
```

### 3. 按风险等级分段
```javascript
let currentRisk = routeWithWeather[0].risk;
let segmentStart = 0;

for (let i = 1; i < routeWithWeather.length; i++) {
    const risk = routeWithWeather[i].risk;
    
    // 如果风险等级变化，创建一个线段
    if (risk.level !== currentRisk.level) {
        this.createSegment(routeWithWeather, segmentStart, i, currentRisk);
        segmentStart = i;
        currentRisk = risk;
    }
}
```

### 4. 创建线段
```javascript
createSegment(routeWithWeather, startIndex, endIndex, risk) {
    const positions = [];
    for (let i = startIndex; i < endIndex; i++) {
        const point = routeWithWeather[i].point;
        positions.push(point.lng, point.lat);
    }
    
    const segmentEntity = this.viewer.entities.add({
        polyline: {
            positions: Cesium.Cartesian3.fromDegreesArray(positions),
            width: 16,
            material: this.getRiskCesiumColor(risk),
            clampToGround: true
        }
    });
}
```

## 优势

1. **完美对齐**：气象线段完全沿着原始航线绘制，不会有偏差
2. **平滑过渡**：保留原始航线的所有弯曲和细节
3. **颜色分段**：相同风险等级的连续段合并为一条线段，性能更好
4. **数据准确**：每个点都有对应的气象数据（基于最近的采样点）

## 性能优化

虽然使用了更多的点，但通过以下方式优化性能：

1. **合并相同颜色段**：连续的相同风险等级合并为一条线段
2. **简单距离计算**：使用欧几里得距离而不是大圆距离
3. **一次性渲染**：所有线段一次性添加到场景中

## 注意事项

1. 原始航线点数越多，气象线段越平滑
2. 采样点间距（50海里）影响气象数据的精度
3. 相邻采样点的风险等级差异越大，颜色过渡越明显
