# Windy 气象图层使用示例

## 快速开始

### 步骤 1：启动系统

```bash
npm run dev
```

### 步骤 2：切换到气象监测选项卡

在顶部导航栏中，点击"气象监测"选项卡。

### 步骤 3：打开气象图层面板

在右侧工具栏中，点击"气象图层"按钮，左侧会展开气象图层控制面板。

### 步骤 4：激活 Windy 图层

1. 在气象图层面板中找到"Windy 气象图层"分组
2. 点击分组标题右侧的开关，展开子图层列表
3. 选择任意子图层（如"风场动画"），点击右侧的开关激活

### 步骤 5：查看效果

- 地图上会叠加显示 Windy 气象图层
- 移动地图时，Windy 图层会自动跟随
- 可以切换不同的气象要素查看

## 使用场景示例

### 场景 1：查看全球风场分布

**目的：** 了解全球风场的实时分布情况

**操作步骤：**
1. 激活"Windy 气象图层" > "风场动画"
2. 观察地图上的风场流线动画
3. 缩放地图查看不同区域的风场细节
4. 风速越大，流线颜色越偏向红色

**应用：** 
- 航线规划时避开强风区域
- 评估矿区作业的风险等级

### 场景 2：查看海浪高度

**目的：** 评估海上作业的安全性

**操作步骤：**
1. 激活"Windy 气象图层" > "海浪高度"
2. 查看目标海域的浪高分布
3. 红色区域表示浪高较大，需要注意

**应用：**
- 判断是否适合进行海上作业
- 规划船舶航线避开大浪区域

### 场景 3：查看降雨预报

**目的：** 了解未来降雨情况

**操作步骤：**
1. 激活"Windy 气象图层" > "降雨预报"
2. 查看降雨量分布
3. 蓝色越深表示降雨量越大

**应用：**
- 预判恶劣天气
- 调整作业计划

### 场景 4：多图层对比

**目的：** 综合分析多种气象要素

**操作步骤：**
1. 先激活"风场动画"，观察风场分布
2. 关闭风场，激活"温度分布"，观察温度变化
3. 再切换到"气压分布"，分析气压系统
4. 综合判断天气系统的演变趋势

**应用：**
- 深入理解天气系统
- 做出更准确的气象预判

## 高级技巧

### 技巧 1：快速切换图层

- 使用键盘快捷键（如果已配置）
- 或在气象图层面板中快速点击不同图层的开关

### 技巧 2：结合其他数据源

- 同时使用 OpenWeatherMap 图层和 Windy 图层
- 对比不同数据源的预报结果
- 提高预报的准确性

### 技巧 3：保存常用配置

- 记录常用的图层组合
- 快速恢复到常用的视图配置

### 技巧 4：性能优化

- 不使用时及时关闭 Windy 图层
- 避免同时激活过多图层
- 在低配置设备上优先使用静态图层

## 常见问题

### Q1：为什么 Windy 图层加载很慢？

**A：** 
- Windy 需要从服务器加载数据，首次加载需要时间
- 检查网络连接是否稳定
- 等待几秒钟让数据完全加载

### Q2：可以同时显示多个 Windy 图层吗？

**A：** 
- 目前设计为同一时间只显示一个 Windy 图层
- 这是为了避免图层叠加导致的视觉混乱
- 可以快速切换不同图层进行对比

### Q3：Windy 图层的数据更新频率是多少？

**A：** 
- Windy 的数据更新频率取决于数据源
- 通常每 3-6 小时更新一次
- 具体更新时间请参考 Windy 官方说明

### Q4：如何查看未来的气象预报？

**A：** 
- 目前版本暂不支持时间轴控制
- 计划在未来版本中添加此功能
- 届时可以查看未来 7-10 天的预报

### Q5：Windy 图层支持离线使用吗？

**A：** 
- 不支持，Windy 图层需要联网使用
- 数据实时从 Windy 服务器获取
- 建议在有网络的环境下使用

## 最佳实践

1. **合理使用图层**
   - 根据实际需求选择合适的图层
   - 不要同时激活过多图层

2. **定期刷新数据**
   - 关闭后重新打开图层可以刷新数据
   - 确保看到的是最新的气象信息

3. **结合其他功能**
   - 配合航线规划功能使用
   - 结合区域监控功能使用
   - 与船舶追踪功能联动

4. **注意性能**
   - 在低配置设备上谨慎使用
   - 及时关闭不需要的图层
   - 避免长时间开启动画图层
