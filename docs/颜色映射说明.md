## 实现说明

### 文件位置
- 颜色映射配置：`src/utils/contractorColors.js`
- 地图组件：`src/components/MapContainer.vue`

### 匹配逻辑
1. **精确匹配**：首先尝试完全匹配承包者名称
2. **模糊匹配**：如果精确匹配失败，进行关键词包含匹配
3. **缩写匹配**：提取括号中的缩写（如 COMRA, BGR）进行匹配
4. **默认颜色**：未匹配到的显示为灰色 (#808080)

### 使用方法

```javascript
import { getContractorColor } from '@/utils/contractorColors';

// 获取承包者颜色
const color = getContractorColor('中国大洋协会 (COMRA)');
// 返回: '#9932CC'
```

## 数据来源

所有颜色配置均基于 ISA (International Seabed Authority) 官方发布的海底矿产勘探区域地图图例。
