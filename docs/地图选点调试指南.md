# 地图选点调试指南

## 问题现象

点击避让点或途经点的"选点"按钮后，按钮显示"选择中"状态，但点击地图没有反应。

## 调试步骤

### 步骤1：打开浏览器控制台

1. 按 F12 打开开发者工具
2. 切换到 Console 标签页
3. 清空控制台（点击 🚫 图标）

### 步骤2：点击"选点"按钮

1. 在航线规划面板中，点击"航线高级配置"展开
2. 点击"+ 添加避让点"
3. 点击"选点"按钮

**查看控制台日志，应该看到：**

```
📍 地图选点事件: {type: "avoid"}
📍 选点状态变化: avoid
   - viewer 存在: true
   - pickPointHandler 存在: false
🗑️ 移除旧的点击处理器（如果有）
✅ 创建新的点击处理器
🖱️ 开始地图选点模式: 避让点
```

### 步骤3：点击地图

在地图上任意位置点击一次。

**查看控制台日志，应该看到：**

```
🖱️ 地图被点击了！类型: avoid
📍 选择了位置 (avoid): 125.000000, 32.500000
✅ 地图选点完成: {lng: 125, lat: 32.5, type: "avoid"}
```

## 问题诊断

### 情况A：没有看到"地图选点事件"日志

**原因：** ShipTrackingPanel 没有发送 pickPoint 事件

**检查：**
1. 确认点击的是"选点"按钮，不是其他按钮
2. 检查 ShipTrackingPanel.vue 中的 `pickAvoidPoint` 函数

**解决方案：**
```javascript
// 在 ShipTrackingPanel.vue 中
const pickAvoidPoint = (index) => {
    console.log('🔵 pickAvoidPoint 被调用:', index);
    // ...
    emit('pickPoint', { type: 'avoid' });
};
```

### 情况B：看到"地图选点事件"但没有"选点状态变化"

**原因：** App.vue 的 handlePickPoint 没有正确设置 pickingPointType

**检查：**
```javascript
// 在 App.vue 中
const handlePickPoint = (data) => {
    console.log('📍 地图选点事件:', data);
    console.log('   - 设置 pickingPointType 为:', data.type);
    pickingPointType.value = data.type;
};
```

### 情况C：看到"选点状态变化"但 viewer 不存在

**原因：** MapContainer 还没有初始化完成

**日志：**
```
📍 选点状态变化: avoid
   - viewer 存在: false  ← 问题在这里
❌ viewer 不存在，无法创建点击处理器
```

**解决方案：**
等待几秒后再点击"选点"按钮，或者刷新页面。

### 情况D：看到"创建新的点击处理器"但点击地图没反应

**原因：** 点击事件被其他元素拦截

**检查：**
1. 查看是否有其他面板覆盖在地图上
2. 检查 CSS 的 `pointer-events` 属性

**测试：**
在控制台执行：
```javascript
// 检查地图 canvas 是否可点击
const canvas = document.querySelector('.cesium-viewer canvas');
console.log('Canvas 存在:', !!canvas);
console.log('Canvas pointer-events:', window.getComputedStyle(canvas).pointerEvents);
```

### 情况E：点击地图后没有"地图被点击了"日志

**原因：** 点击处理器没有正确绑定

**可能的问题：**
1. `pickPointHandler` 被其他代码销毁了
2. Cesium 的事件系统有问题

**解决方案：**
在控制台手动测试：
```javascript
// 获取 viewer
const viewer = window.viewer; // 如果暴露了的话

// 创建测试处理器
const testHandler = new Cesium.ScreenSpaceEventHandler(viewer.scene.canvas);
testHandler.setInputAction((click) => {
    console.log('✅ 测试点击成功！', click.position);
}, Cesium.ScreenSpaceEventType.LEFT_CLICK);
```

### 情况F：看到"地图被点击了"但没有后续日志

**原因：** `cartesian` 为 null（点击到了天空或其他非地球表面）

**解决方案：**
确保点击地球表面，不要点击天空或UI元素。

## 完整的日志流程

正常情况下，从点击"选点"到完成选点，应该看到以下完整日志：

```
1. 点击"选点"按钮
   📍 地图选点事件: {type: "avoid"}

2. App.vue 处理事件
   📍 选点状态变化: avoid
      - viewer 存在: true
      - pickPointHandler 存在: false
   ✅ 创建新的点击处理器
   🖱️ 开始地图选点模式: 避让点

3. 点击地图
   🖱️ 地图被点击了！类型: avoid
   📍 选择了位置 (avoid): 125.000000, 32.500000

4. 发送结果
   ✅ 地图选点完成: {lng: 125, lat: 32.5, type: "avoid"}

5. ShipTrackingPanel 接收结果
   ✅ 避让点已设置: 0 125 32.5
```

## 快速测试命令

在浏览器控制台中执行以下命令进行快速测试：

```javascript
// 1. 检查 App.vue 的状态
console.log('pickingPointType:', window.debugApp?.pickingPointType);

// 2. 手动触发选点
if (window.debugApp) {
    window.debugApp.handlePickPoint({ type: 'avoid' });
}

// 3. 检查 MapContainer 的 viewer
// （需要在 MapContainer 中暴露 viewer）

// 4. 手动设置选点结果
if (window.debugApp?.shipTrackingRef) {
    window.debugApp.shipTrackingRef.setPickedPoint(125.0, 32.5, 'avoid');
}
```

## 常见解决方案

### 解决方案1：刷新页面

最简单的方法，清除所有状态：
1. 按 Ctrl+Shift+R 硬刷新
2. 清除浏览器缓存

### 解决方案2：检查事件绑定

确认 App.vue 中的事件绑定：
```vue
<ShipTrackingPanel 
    @pickPoint="handlePickPoint"
    ...
/>

<MapContainer 
    :pickingPointType="pickingPointType"
    @pointPicked="handlePointPicked"
    ...
/>
```

### 解决方案3：检查 ref 绑定

确认 ShipTrackingPanel 的 ref：
```vue
<ShipTrackingPanel 
    ref="shipTrackingRef"
    ...
/>
```

### 解决方案4：添加临时调试代码

在 MapContainer.vue 的 watch 中添加：
```javascript
watch(() => props.pickingPointType, (newType) => {
    console.log('=== 开始调试 ===');
    console.log('newType:', newType);
    console.log('viewer:', viewer);
    console.log('pickPointHandler:', pickPointHandler);
    console.log('=== 结束调试 ===');
    // ... 原有代码
});
```
