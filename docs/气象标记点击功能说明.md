# 气象标记点击功能说明

## 功能概述

点击航线上的气象标记点，会弹出该点的详细气象信息面板。

## 实现方式

### 1. 渲染可点击的标记点

在渲染气象线段的同时，每隔一定间隔渲染小的标记点：

```javascript
// 每隔几个点放一个标记，避免太密集
const markerInterval = Math.max(1, Math.floor(this.weatherData.length / 20)); // 最多20个标记

for (let i = 0; i < this.weatherData.length; i += markerInterval) {
    const data = this.weatherData[i];
    
    // 创建小的透明标记点
    const entity = this.viewer.entities.add({
        id: `weather_marker_${i}`,
        position: Cesium.Cartesian3.fromDegrees(point.lng, point.lat, 500),
        point: {
            pixelSize: 8,
            color: Cesium.Color.fromCssColorString(risk.color).withAlpha(0.6),
            outlineColor: Cesium.Color.WHITE,
            outlineWidth: 1
        }
    });
    
    // 存储数据（用于点击时显示）
    entity._weatherData = weather;
    entity._riskData = risk;
    entity._segmentData = data;
}
```

### 2. 点击事件处理

MapContainer中已有完整的点击事件处理逻辑：

```javascript
// 检测点击的实体
const pickedObject = viewer.scene.pick(correctedPosition);

if (Cesium.defined(pickedObject) && pickedObject.id) {
    const entity = pickedObject.id;
    
    // 如果点击的是气象标记
    if (entity.id && entity.id.startsWith('weather_marker_')) {
        // 读取存储的数据
        const weatherData = {
            weather: entity._weatherData,
            risk: entity._riskData
        };
        
        // 格式化详情
        const details = routeWeatherLayer.showWeatherDetails(weatherData);
        
        // 显示气象详情窗口
        selectedWeather.value = details;
        weatherInfoPosition.value = {
            x: correctedPosition.x + 20,
            y: correctedPosition.y - 100
        };
    }
}
```

### 3. 气象详情格式化

`showWeatherDetails` 方法将原始气象数据格式化为可显示的格式：

```javascript
showWeatherDetails(weatherData) {
    const { weather, risk } = weatherData;
    
    return {
        title: `${risk.emoji} ${risk.description}`,
        items: [
            { label: '数据时间', value: formatTime(weather.timestamp) },
            { label: '风速', value: `${weather.windspeed || 'N/A'} m/s` },
            { label: '风向', value: `${weather.winddir || 'N/A'}°` },
            { label: '浪高', value: `${weather.waveheight || 'N/A'} m` },
            { label: '涌浪高', value: `${weather.swellheight || 'N/A'} m` },
            { label: '能见度', value: `${weather.visibility || 'N/A'} km` },
            { label: '气温', value: `${weather.temperature || 'N/A'} °C` },
            { label: '气压', value: `${weather.pressure || 'N/A'} hPa` }
        ]
    };
}
```

### 4. UI显示

气象信息面板使用Vue组件渲染：

```vue
<div v-if="selectedWeather" 
     :style="{ left: weatherInfoPosition.x + 'px', top: weatherInfoPosition.y + 'px' }"
     class="absolute w-[22rem] bg-slate-950/95 backdrop-blur-xl border-2 border-cyan-500/50">
    
    <!-- 标题 -->
    <div class="flex items-center justify-between p-4 border-b border-cyan-500/30">
        <span class="font-bold text-lg">{{ selectedWeather.title }}</span>
        <button @click="closeWeatherInfo">✕</button>
    </div>
    
    <!-- 数据列表 -->
    <div class="p-4">
        <div v-for="item in selectedWeather.items" :key="item.label" 
             class="flex justify-between py-2 border-b border-cyan-500/20">
            <span class="text-cyan-400/80">{{ item.label }}</span>
            <span class="text-white font-bold">{{ item.value }}</span>
        </div>
    </div>
</div>
```

## 标记点分布策略

为了避免标记点太密集，采用智能间隔策略：

```javascript
const markerInterval = Math.max(1, Math.floor(this.weatherData.length / 20));
```

**示例**：
- 航线有100个点 → 间隔5个点 → 显示20个标记
- 航线有50个点 → 间隔2个点 → 显示25个标记
- 航线有10个点 → 间隔1个点 → 显示10个标记

## 标记点样式

| 属性 | 值 | 说明 |
|------|---|------|
| 大小 | 8px | 小巧不遮挡 |
| 颜色 | 风险等级颜色 | 绿/黄/橙/红 |
| 透明度 | 0.6 | 半透明 |
| 边框 | 白色1px | 易于识别 |

## 信息面板内容

### 标题
显示风险等级和描述：
- 🟢 安全 (5级风, 1.2m浪)
- 🟡 注意 (7级风, 2.5m浪)
- 🟠 警告 (8级风, 3.8m浪)
- 🔴 危险 (10级风, 5.2m浪)

### 数据项
- **数据时间**：预计到达该点的时间
- **风速**：m/s（米/秒）
- **风向**：度（0-360°）
- **浪高**：米
- **涌浪高**：米
- **涌浪方向**：度
- **能见度**：公里
- **气温**：摄氏度
- **气压**：百帕

## 交互流程

1. **规划航线** → 显示原始航线（紫色）
2. **点击"航线气象"** → 显示彩色线段和标记点
3. **点击标记点** → 弹出气象信息面板
4. **查看详情** → 了解该点的气象状况
5. **关闭面板** → 点击×或点击地图其他位置

## 优势

1. **精准定位**：点击任意标记点查看该位置的气象
2. **详细信息**：显示完整的气象数据
3. **时间准确**：显示预计到达该点的时间
4. **视觉清晰**：标记点颜色对应风险等级
5. **不遮挡**：标记点小巧，不影响查看线段

## 注意事项

1. **标记点数量**：最多20个，避免太密集
2. **点击区域**：标记点较小（8px），需要精确点击
3. **数据来源**：显示的是该点预测到达时间的气象数据
4. **面板位置**：自动调整，避免超出屏幕边界

## 示例场景

### 场景1：查看危险区域详情
1. 地图上显示红色线段（危险区域）
2. 点击红色标记点
3. 面板显示：🔴 危险 (10级风, 5.2m浪)
4. 查看详细数据：风速20m/s，浪高5.2m

### 场景2：对比不同位置气象
1. 点击起点附近的绿色标记 → 风速5m/s
2. 关闭面板
3. 点击中段的黄色标记 → 风速10m/s
4. 关闭面板
5. 点击终点附近的红色标记 → 风速20m/s

## 技术细节

### 坐标修正
考虑CSS scale缩放导致的坐标偏差：
```javascript
const scaleX = window.innerWidth / 1920;
const scaleY = window.innerHeight / 1080;
const correctedPosition = new Cesium.Cartesian2(
    click.position.x / scaleX,
    click.position.y / scaleY
);
```

### 面板位置计算
确保面板不超出屏幕：
```javascript
weatherInfoPosition.value = {
    x: Math.min(correctedPosition.x + 20, window.innerWidth / scaleX - 370),
    y: Math.max(correctedPosition.y - 100, 10)
};
```

### 数据存储
直接在entity上存储数据，避免Cesium包装：
```javascript
entity._weatherData = weather;  // 原始气象数据
entity._riskData = risk;        // 风险等级
entity._segmentData = data;     // 完整数据
```
