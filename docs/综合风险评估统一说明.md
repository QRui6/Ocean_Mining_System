# 综合风险评估统一说明

## 概述
已将气象风险评估逻辑统一，地图图层和数据表格使用相同的评估标准。

## 统一的风险评估标准

### 评估指标
1. **风速** (windspeed, m/s) → 转换为蒲福风级
2. **浪高** (waveheight, m)

### 风险等级划分

采用**综合评估**原则：风速和浪高任一指标超标，即升级到对应风险等级。

| 风险等级 | 风速条件 | 浪高条件 | 颜色 | 说明 |
|---------|---------|---------|------|------|
| **安全** (safe) | < 6级风 (< 10.8 m/s) | ≤ 2m | 绿色 #00FF7F | 适合航行 |
| **注意** (caution) | ≥ 6级风 (10.8-17.1 m/s) | > 2m | 黄色 #FFFF00 | 需注意观察 |
| **警告** (warning) | = 8级风 (17.2-20.7 m/s) | > 3m | 橙色 #FFA500 | 需谨慎航行 |
| **危险** (danger) | > 8级风 (> 20.8 m/s) | > 4m | 红色 #FF4500 | 不适合航行 |

### 蒲福风级转换公式
```javascript
beaufort = Math.round(Math.pow(windSpeed / 0.836, 2/3))
```

### 蒲福风级对照表

| 风级 | 风速 (m/s) | 名称 | 海面状况 |
|------|-----------|------|---------|
| 0 | < 0.3 | 无风 | 平静如镜 |
| 1 | 0.3-1.5 | 软风 | 微波 |
| 2 | 1.6-3.3 | 轻风 | 小波 |
| 3 | 3.4-5.4 | 微风 | 小浪 |
| 4 | 5.5-7.9 | 和风 | 轻浪 |
| 5 | 8.0-10.7 | 清劲风 | 中浪 |
| 6 | 10.8-13.8 | 强风 | 大浪 |
| 7 | 13.9-17.1 | 疾风 | 巨浪 |
| 8 | 17.2-20.7 | 大风 | 狂浪 |
| 9 | 20.8-24.4 | 烈风 | 狂涛 |
| 10 | 24.5-28.4 | 狂风 | 狂涛 |
| 11 | 28.5-32.6 | 暴风 | 狂涛 |
| 12 | > 32.7 | 飓风 | 狂涛 |

## 评估逻辑

### 综合评估（OR逻辑）
```javascript
if (风力 > 8级 OR 浪高 > 4m) → 危险
else if (风力 = 8级 OR 浪高 > 3m) → 警告
else if (风力 ≥ 6级 OR 浪高 > 2m) → 注意
else → 安全
```

### 示例

**示例1：风大浪小**
- 风速：18 m/s (8级风)
- 浪高：2.5 m
- 评估：**警告** (因为风力达到8级)

**示例2：风小浪大**
- 风速：8 m/s (5级风)
- 浪高：3.5 m
- 评估：**警告** (因为浪高超过3m)

**示例3：风浪都大**
- 风速：22 m/s (9级风)
- 浪高：5 m
- 评估：**危险** (风力和浪高都超标)

**示例4：风浪适中**
- 风速：9 m/s (5级风)
- 浪高：1.8 m
- 评估：**安全** (风力和浪高都在安全范围)

## 代码结构

### 公共模块
**文件：** `src/utils/weatherRiskAssessment.js`

**导出函数：**
- `calculateBeaufortScale(windSpeed)` - 计算蒲福风级
- `calculateRiskLevel(weather)` - 计算综合风险等级
- `getRiskClasses(level)` - 获取CSS类名
- `getWindSpeedRiskLevel(windSpeed)` - 仅基于风速的风险等级
- `getWaveHeightRiskLevel(waveHeight)` - 仅基于浪高的风险等级

### 使用位置

**1. 气象图层** (`src/utils/routeWeatherLayer.js`)
```javascript
import { calculateRiskLevel } from './weatherRiskAssessment.js';

// 计算每个节点的风险等级
const risk = calculateRiskLevel(weatherData);
```

**2. 数据表格** (`src/components/WeatherListTable.vue`)
```javascript
import { 
    calculateRiskLevel, 
    getRiskClasses, 
    getWindSpeedRiskLevel, 
    getWaveHeightRiskLevel 
} from '../utils/weatherRiskAssessment.js';

// 显示综合风险等级
const risk = item.risk;
const classes = getRiskClasses(risk.level);
```

## 优势

### 1. 标准统一
- 地图和表格使用相同的评估逻辑
- 避免用户混淆

### 2. 更加安全
- 采用OR逻辑，任一指标超标即升级
- 更保守的评估策略

### 3. 易于维护
- 评估逻辑集中在一个文件
- 修改标准只需改一处

### 4. 可扩展
- 可以轻松添加新的评估指标（如能见度、海流等）
- 可以根据船舶类型调整阈值

## 未来改进方向

### 1. 船舶类型适配
不同吨位的船舶抗风浪能力不同：
- 小型船舶（< 1000吨）：降低阈值
- 中型船舶（1000-10000吨）：当前标准
- 大型船舶（> 10000吨）：提高阈值

### 2. 增加评估因子
- **能见度**：< 1000m 为危险
- **风向与航向夹角**：逆风更危险
- **海流速度**：强海流增加风险
- **气温**：极端温度影响设备

### 3. 时间维度
- 接入支持未来预报的气象API
- 根据预计到达时间获取对应气象数据
- 提供趋势预测

### 4. 智能建议
- 根据风险等级提供航行建议
- 推荐最佳出发时间
- 建议备选航线
