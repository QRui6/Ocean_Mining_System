# 矿种筛选问题修复说明

## 问题原因

数据中的矿种名称与 constants.js 中定义的不完全一致：

### 数据中的实际矿种名称
```json
"mineral": "多金属结核 (PMN)"
"mineral": "富钴结壳 (CFC)"
"mineral": "多金属硫化物 (PMS)"
"mineral": "保留区 (PMN)"
"mineral": "保留区 (CFC)"
"mineral": "环境特别受关注区"
```

### constants.js 中定义的矿种
```javascript
MINERAL_TYPES = ['多金属结核', '富钴铁锰结壳', '多金属硫化物']
```

### 不匹配的情况
1. 数据中包含括号和英文缩写，如 `"多金属结核 (PMN)"`
2. 富钴结壳的名称不一致：
   - 数据中：`"富钴结壳 (CFC)"`
   - 定义中：`"富钴铁锰结壳"`

## 解决方案

使用模糊匹配逻辑，支持以下匹配方式：

### 1. 直接匹配
```javascript
if (entityMineral === mineral) {
    mineralMatch = true;
}
```

### 2. 包含匹配
```javascript
if (entityMineral.includes(mineral)) {
    mineralMatch = true;
}
```
这样可以匹配：
- `"多金属结核 (PMN)"` 包含 `"多金属结核"` ✅
- `"多金属硫化物 (PMS)"` 包含 `"多金属硫化物"` ✅

### 3. 特殊处理富钴结壳
```javascript
if (mineral === '富钴铁锰结壳' && entityMineral.includes('富钴结壳')) {
    mineralMatch = true;
}
```
这样可以匹配：
- 选择 `"富钴铁锰结壳"` 时，匹配 `"富钴结壳 (CFC)"` ✅

## 完整的筛选逻辑

```javascript
// 矿种筛选（模糊匹配）
if (mineral) {
    let mineralMatch = false;
    if (entityMineral) {
        // 直接匹配
        if (entityMineral === mineral) {
            mineralMatch = true;
        }
        // 包含匹配（处理括号和缩写）
        else if (entityMineral.includes(mineral)) {
            mineralMatch = true;
        }
        // 特殊处理：富钴结壳 vs 富钴铁锰结壳
        else if (mineral === '富钴铁锰结壳' && entityMineral.includes('富钴结壳')) {
            mineralMatch = true;
        }
    }
    if (!mineralMatch) {
        matches = false;
    }
}

// 大洋筛选
if (ocean) {
    const oceanKey = ocean.replace('洋', '');
    if (!entityLocation || !entityLocation.includes(oceanKey)) {
        matches = false;
    }
}

// 国家筛选
if (country) {
    if (entitySponsor !== country) {
        matches = false;
    }
}
```
