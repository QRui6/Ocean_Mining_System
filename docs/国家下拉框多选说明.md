# 国家下拉框多选功能说明

## 功能概述

国家筛选使用下拉框进行选择，节省空间，已选中的国家会以标签形式显示在下方。

## UI 布局

```
┌─────────────────────────────────────┐
│ 所属国家 (已选 3)          [清空]   │
├─────────────────────────────────────┤
│ [下拉框: -- 选择国家 --]            │
├─────────────────────────────────────┤
│ 已选标签区域：                       │
│ [中国 ✕] [日本 ✕] [俄罗斯 ✕]       │
└─────────────────────────────────────┘
```

## 操作方式

### 1. 选择国家
- 点击下拉框
- 从列表中选择一个国家
- 选中后，国家会以黄色标签形式显示在下方
- 下拉框自动重置为"-- 选择国家 --"
- 已选中的国家在下拉框中会显示"(已选)"并禁用

### 2. 移除国家
- **单个移除**：点击标签上的 ✕ 按钮
- **批量清空**：点击右上角的"清空"按钮

### 3. 查看已选
- 标题旁显示已选数量：`(已选 3)`
- 下方显示所有已选国家的黄色标签

## 视觉效果

### 下拉框
- 背景：深色半透明 `bg-slate-800/80`
- 边框：默认灰色，悬停/聚焦时变为青色
- 已选项：显示"(已选)"并禁用

### 已选标签
- 背景：黄色 `bg-yellow-500`
- 文字：黑色粗体
- 发光效果：`shadow-[0_0_8px_rgba(250,204,21,0.4)]`
- 移除按钮：✕ 符号，悬停时变红色

### 清空按钮
- 背景：红色 `bg-red-600/80`
- 仅在有选中项时显示
- 悬停时变为深红色

## 使用示例

### 示例 1：选择单个国家
1. 点击下拉框
2. 选择"中国"
3. 下方出现黄色标签：`[中国 ✕]`
4. 地图上中国的矿区被高亮

### 示例 2：选择多个国家
1. 点击下拉框，选择"中国"
2. 再次点击下拉框，选择"日本"
3. 再次点击下拉框，选择"俄罗斯"
4. 下方显示三个标签：`[中国 ✕] [日本 ✕] [俄罗斯 ✕]`
5. 地图上这三个国家的矿区都被高亮

### 示例 3：移除单个国家
1. 已选：中国、日本、俄罗斯
2. 点击"日本"标签上的 ✕ 按钮
3. 日本标签消失
4. 地图上日本的矿区不再高亮

### 示例 4：清空所有国家
1. 已选：中国、日本、俄罗斯
2. 点击右上角的"清空"按钮
3. 所有标签消失
4. 地图恢复到只按矿种和大洋筛选的状态

## 技术实现

### 下拉框选择
```javascript
const onCountrySelect = (event) => {
    const country = event.target.value;
    if (country && !activeCountries.value.includes(country)) {
        activeCountries.value.push(country);
        emitFilter();
    }
    // 重置下拉框
    event.target.value = '';
};
```

### 移除单个国家
```javascript
const removeCountry = (country) => {
    const index = activeCountries.value.indexOf(country);
    if (index > -1) {
        activeCountries.value.splice(index, 1);
        emitFilter();
    }
};
```

### 清空所有国家
```javascript
const clearCountries = () => {
    activeCountries.value = [];
    emitFilter();
};
```

### 禁用已选项
```html
<option 
    :value="c" 
    :disabled="activeCountries.includes(c)"
>
    {{ c }} {{ activeCountries.includes(c) ? '(已选)' : '' }}
</option>
```

## 优势

### 1. 节省空间
- 不需要显示所有国家按钮
- 下拉框收起时只占一行
- 特别适合国家数量较多的情况

### 2. 清晰直观
- 已选国家以标签形式展示
- 一目了然当前选择了哪些国家
- 每个标签都可以单独移除

### 3. 防止重复选择
- 已选国家在下拉框中禁用
- 显示"(已选)"提示
- 避免重复添加

### 4. 操作便捷
- 下拉框自动重置，方便连续选择
- 标签上的 ✕ 按钮方便单个移除
- "清空"按钮方便批量清除

## 与其他筛选的配合

### 矿种 + 大洋 + 国家
```
矿种：[多金属结核] [富钴铁锰结壳]  (已选 2)
大洋：[太平洋]                      (已选 1)
国家：下拉框 + [中国 ✕] [日本 ✕]   (已选 2)

结果：(多金属结核 OR 富钴铁锰结壳) 
      AND 太平洋 
      AND (中国 OR 日本)
```

## 注意事项

1. ✅ 下拉框选择后自动重置，方便连续选择
2. ✅ 已选国家在下拉框中禁用，防止重复
3. ✅ 标签显示已选国家，清晰直观
4. ✅ 每个标签都可以单独移除
5. ✅ "清空"按钮仅在有选中项时显示
6. ✅ 显示已选数量，方便了解筛选状态
7. ✅ 标签区域自动换行，适应不同数量的选择
