# 多选筛选功能说明

## 功能概述

所有筛选条件（矿种、大洋、国家）现在都支持多选，可以同时选择多个选项。

## 多选逻辑

### 同类型内：OR 关系
在同一个筛选类型内，多个选项之间是 **OR（或）** 关系：

- **矿种**：选择"多金属结核"和"富钴铁锰结壳" → 显示**多金属结核 OR 富钴铁锰结壳**的矿区
- **大洋**：选择"太平洋"和"印度洋" → 显示**太平洋 OR 印度洋**的矿区
- **国家**：选择"中国"和"日本" → 显示**中国 OR 日本**的矿区

### 不同类型间：AND 关系
不同筛选类型之间是 **AND（且）** 关系：

- 选择矿种"多金属结核" + 大洋"太平洋" → 显示**多金属结核 AND 太平洋**的矿区
- 选择矿种"多金属结核" + 大洋"太平洋" + 国家"中国" → 显示**多金属结核 AND 太平洋 AND 中国**的矿区

## 操作方式

### 矿种类型（按钮多选）
- 点击按钮选中（蓝色高亮）
- 再次点击取消选中
- 可以同时选中多个矿种
- 显示已选数量：`(已选 2)`

### 所属大洋（按钮多选）
- 点击按钮选中（青色高亮）
- 再次点击取消选中
- 可以同时选中多个大洋
- 显示已选数量：`(已选 2)`

### 所属国家（按钮多选）
- 点击按钮选中（黄色高亮）
- 再次点击取消选中
- 可以同时选中多个国家
- 显示已选数量：`(已选 3)`
- 点击"清空"按钮可以一次性清除所有国家选择
- 国家列表支持滚动，最大高度 200px

## 使用示例

### 示例 1：查看多种矿种
1. 点击"多金属结核"
2. 点击"富钴铁锰结壳"
3. 地图显示：所有多金属结核矿区 + 所有富钴铁锰结壳矿区

### 示例 2：查看多个大洋
1. 点击"太平洋"
2. 点击"印度洋"
3. 地图显示：太平洋的所有矿区 + 印度洋的所有矿区

### 示例 3：查看多个国家
1. 点击"中国"
2. 点击"日本"
3. 点击"俄罗斯"
4. 地图显示：中国 + 日本 + 俄罗斯的所有矿区

### 示例 4：复杂组合筛选
1. 矿种：选择"多金属结核"和"多金属硫化物"
2. 大洋：选择"太平洋"
3. 国家：选择"中国"和"日本"
4. 地图显示：
   - (多金属结核 OR 多金属硫化物) 
   - AND 太平洋 
   - AND (中国 OR 日本)

### 示例 5：取消选择
- **单个取消**：再次点击已选中的按钮
- **批量取消**：点击国家区域的"清空"按钮
- **全部取消**：取消所有选择后，地图恢复初始状态

## 视觉反馈

### 选中状态
- **矿种**：蓝色渐变背景 + 蓝色边框 + 发光效果
- **大洋**：青色背景 + 青色边框 + 发光效果
- **国家**：黄色背景 + 黑色文字 + 发光效果

### 已选数量
每个筛选类型旁边显示已选数量：
```
矿种类型 (已选 2)
所属大洋 (已选 1)
所属国家 (已选 3)
```

### 地图显示
- ✅ 匹配矿区：黄色边框（3px）+ 原色 + 0.8 透明度
- ⚪ 不匹配矿区：白色边框（1px）+ 原色 + 0.2 透明度
- 🔄 无筛选时：白色边框（1px）+ 原色 + 0.8 透明度

## 技术实现

### 数据结构
```javascript
// 旧版（单选）
filters: {
    mineral: '多金属结核',
    ocean: '太平洋',
    country: '中国'
}

// 新版（多选）
filters: {
    minerals: ['多金属结核', '富钴铁锰结壳'],
    oceans: ['太平洋', '印度洋'],
    countries: ['中国', '日本', '俄罗斯']
}
```

### 筛选逻辑
```javascript
// 矿种筛选（OR关系）
if (minerals.length > 0) {
    let mineralMatch = false;
    for (const mineral of minerals) {
        if (entityMineral.includes(mineral)) {
            mineralMatch = true;
            break;
        }
    }
    if (!mineralMatch) matches = false;
}

// 大洋筛选（OR关系）
if (oceans.length > 0) {
    let oceanMatch = false;
    for (const ocean of oceans) {
        if (entityLocation.includes(ocean)) {
            oceanMatch = true;
            break;
        }
    }
    if (!oceanMatch) matches = false;
}

// 国家筛选（OR关系）
if (countries.length > 0) {
    let countryMatch = false;
    for (const country of countries) {
        if (entitySponsor === country) {
            countryMatch = true;
            break;
        }
    }
    if (!countryMatch) matches = false;
}
```

## 注意事项

1. ✅ 同类型内多选为 OR 关系（满足任一条件即可）
2. ✅ 不同类型间为 AND 关系（必须同时满足）
3. ✅ 支持任意数量的多选组合
4. ✅ 国家列表支持滚动，最大高度 200px
5. ✅ 显示已选数量，方便了解当前筛选状态
6. ✅ 国家区域提供"清空"按钮，快速清除所有国家选择
7. ✅ 取消所有筛选后，地图自动恢复初始状态

## 优势

1. **更灵活**：可以同时查看多个矿种/大洋/国家的矿区
2. **更直观**：通过已选数量和高亮状态，清楚了解当前筛选
3. **更高效**：不需要多次切换，一次性选择多个条件
4. **更友好**：支持快速清空，方便重新筛选
