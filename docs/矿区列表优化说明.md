# 矿区列表优化说明

## 优化内容

### 1. 边距调整
- **右侧边距**：从 `right-0` 改为 `right-8`，留出 2rem 空间
- **底部边距**：从 `bottom-0` 改为 `bottom-4`，留出 1rem 空间
- 避免内容紧贴边缘，视觉更舒适

### 2. 表格滚动
- 表格内容区域设置 `overflow-auto`
- 表头使用 `sticky top-0` 固定，滚动时始终可见
- 自定义滚动条样式 `custom-scrollbar`
- 表格可以上下滚动查看所有数据

### 3. 数据筛选
- 表格数据根据左侧面板的筛选条件自动过滤
- 支持矿种、大洋、国家的多选筛选
- 筛选逻辑与地图筛选保持一致
- 实时更新显示匹配的矿区数据

### 4. 分页功能
- 每页显示 10 条数据
- 分页组件包含：
  - 上一页/下一页按钮
  - 页码按钮（当前页高亮）
  - 智能页码显示（总页数>7时显示省略号）
  - 数据统计信息
- 切换筛选条件时自动重置到第一页

## 功能特性

### 分页组件

#### 页码显示逻辑
- **总页数 ≤ 7**：显示所有页码
  ```
  [上一页] 1 2 3 4 5 [下一页]
  ```

- **当前页在前部**：
  ```
  [上一页] 1 2 3 4 5 ... 10 [下一页]
  ```

- **当前页在中部**：
  ```
  [上一页] 1 ... 4 5 6 ... 10 [下一页]
  ```

- **当前页在后部**：
  ```
  [上一页] 1 ... 6 7 8 9 10 [下一页]
  ```

#### 按钮状态
- **当前页**：青色背景 + 发光效果
- **可点击页**：灰色背景，悬停时变浅
- **禁用状态**：上一页（第1页时）、下一页（最后一页时）

### 数据筛选

#### 筛选流程
```
用户在左侧面板选择筛选条件
  ↓
LeftPanel emit('filterChange')
  ↓
App.vue 更新 filters
  ↓
computed filteredMiningData 自动计算
  ↓
传递给 BottomTable
  ↓
表格显示筛选后的数据
```

#### 筛选逻辑
```javascript
// 矿种筛选（OR关系）
if (minerals.length > 0) {
    const mineralMatch = minerals.some(mineral => {
        if (item.mineral === mineral) return true;
        if (item.mineral.includes(mineral)) return true;
        if (mineral === '富钴铁锰结壳' && item.mineral.includes('富钴结壳')) return true;
        return false;
    });
    if (!mineralMatch) matches = false;
}

// 大洋筛选（OR关系）
if (oceans.length > 0) {
    const oceanMatch = oceans.some(ocean => {
        const oceanKey = ocean.replace('洋', '');
        return item.location && item.location.includes(oceanKey);
    });
    if (!oceanMatch) matches = false;
}

// 国家筛选（OR关系）
if (countries.length > 0) {
    const countryMatch = countries.some(country => item.sponsor === country);
    if (!countryMatch) matches = false;
}
```

## 技术实现

### 分页计算
```javascript
// 总页数
const totalPages = computed(() => 
    Math.ceil(totalCount.value / pageSize.value)
);

// 当前页数据
const paginatedData = computed(() => {
    const start = (currentPage.value - 1) * pageSize.value;
    const end = start + pageSize.value;
    return props.miningData.slice(start, end);
});
```

### 智能页码
```javascript
const visiblePages = computed(() => {
    const pages = [];
    const total = totalPages.value;
    const current = currentPage.value;
    
    if (total <= 7) {
        // 显示所有页码
        for (let i = 1; i <= total; i++) pages.push(i);
    } else {
        // 显示部分页码 + 省略号
        if (current <= 4) {
            for (let i = 1; i <= 5; i++) pages.push(i);
            pages.push('...');
            pages.push(total);
        } else if (current >= total - 3) {
            pages.push(1);
            pages.push('...');
            for (let i = total - 4; i <= total; i++) pages.push(i);
        } else {
            pages.push(1);
            pages.push('...');
            for (let i = current - 1; i <= current + 1; i++) pages.push(i);
            pages.push('...');
            pages.push(total);
        }
    }
    
    return pages;
});
```

### 数据监听
```javascript
// 监听数据变化，重置到第一页
watch(() => props.miningData, () => {
    currentPage.value = 1;
});
```
