## 🔑 核心知识点

### 1. 为什么需要 @vitejs/plugin-vue？
这是 Vite 识别和编译 `.vue` 文件的**必需插件**。没有它，Vite 无法处理 Vue 单文件组件。

```typescript
// vite.config.ts
import vue from '@vitejs/plugin-vue';

export default defineConfig({
  plugins: [vue()], // 必须添加！
});
```

### 2. package.json 的关键配置

```json
{
  "type": "module",           // 启用 ES 模块
  "scripts": {
    "dev": "vite",            // 开发命令
    "build": "vite build"     // 构建命令
  },
  "dependencies": {
    "vue": "^3.5.24"          // 运行时依赖
  },
  "devDependencies": {
    "@vitejs/plugin-vue": "^5.2.1",  // 必需！
    "vite": "^6.2.0"          // 构建工具
  }
}
```

### 3. 入口文件的连接关系

```
index.html
    ↓ (引入)
main.js
    ↓ (导入)
App.vue
    ↓ (导入)
components/*.vue
```

### 4. Vue 3 Composition API 基础

```vue
<script>
import { ref, computed, watch, onMounted } from 'vue';

export default {
  setup() {
    // 响应式数据
    const count = ref(0);
    
    // 计算属性
    const double = computed(() => count.value * 2);
    
    // 监听器
    watch(count, (newVal) => {
      console.log('count changed:', newVal);
    });
    
    // 生命周期
    onMounted(() => {
      console.log('组件已挂载');
    });
    
    return { count, double };
  }
};
</script>
```

## 🎓 关键概念对比

### Vue 2 vs Vue 3

| 特性 | Vue 2 | Vue 3 |
|------|-------|-------|
| API 风格 | Options API | Composition API |
| 响应式 | Object.defineProperty | Proxy |
| 性能 | 较慢 | 更快 |
| TypeScript | 支持一般 | 原生支持 |
| 包大小 | 较大 | 更小 |

### Webpack vs Vite

| 特性 | Webpack | Vite |
|------|---------|------|
| 启动速度 | 慢 | 快 |
| 热更新 | 较慢 | 极快 |
| 配置 | 复杂 | 简单 |
| 生态 | 成熟 | 新兴 |
