# 矿区筛选功能使用说明

## 功能概述

左侧面板支持筛选功能，可以根据矿种类型、所属大洋、所属国家进行单独或联级筛选。

## 筛选选项

### 1. 矿种类型（固定 3 类 - 按钮）
- 多金属结核
- 富钴铁锰结壳
- 多金属硫化物

**操作方式**：点击按钮选中，再次点击取消选中

### 2. 所属大洋（固定 3 类 - 按钮）
- 太平洋
- 印度洋
- 大西洋

**操作方式**：点击按钮选中，再次点击取消选中

### 3. 所属国家（动态加载 - 下拉框）
- 从 GeoJSON 数据的 `sponsor` 字段中提取
- 使用下拉框显示所有实际存在的担保国
- 不受矿种和大洋选择的影响，始终显示全部国家
- 包含"-- 全部国家 --"选项和"取消"按钮

**操作方式**：
- 从下拉框中选择国家
- 点击"取消"按钮清除选择
- 选择"-- 全部国家 --"也可清除筛选

## 筛选方式

### 单独筛选
点击任意一个筛选条件，地图会高亮显示匹配的矿区：
- 点击"多金属结核" → 只高亮多金属结核矿区
- 点击"太平洋" → 只高亮太平洋区域的矿区
- 选择某个国家 → 只高亮该国家的矿区

### 联级筛选
可以同时选择多个条件，系统会显示同时满足所有条件的矿区：
- 选择"多金属结核" + "太平洋" → 显示太平洋的多金属结核矿区
- 选择"多金属结核" + "太平洋" + "中国" → 显示中国在太平洋的多金属结核矿区

### 取消筛选
- **矿种和大洋**：再次点击已选中的按钮，可以取消该筛选条件
- **国家**：点击"取消"按钮或选择"-- 全部国家 --"可以取消国家筛选
- **恢复初始状态**：取消所有筛选条件后，地图自动恢复到初始状态（所有矿区白色边框，无高亮）

## 视觉效果

### 无筛选条件时
- ⚪ 所有矿区保持初始状态
- ⚪ 白色边框（1px）
- ⚪ 原色显示（0.8 透明度）

### 匹配的矿区
- ✅ 保持原有的官方图例颜色
- ✅ 边框变为**黄色高亮**（3px 宽度）
- ✅ 透明度保持 0.8

### 不匹配的矿区
- ⚪ 颜色变为半透明（透明度 0.2）
- ⚪ 边框变为白色半透明（1px 宽度）
- ⚪ 仍然可见，但明显弱化

## 使用示例

### 示例 1：查看中国的所有矿区
1. 在"所属国家"下拉框中选择"中国"
2. 地图上中国的矿区会用黄色边框高亮

### 示例 2：查看太平洋的多金属结核矿区
1. 点击"矿种类型"中的"多金属结核"
2. 点击"所属大洋"中的"太平洋"
3. 地图上只有同时满足这两个条件的矿区会高亮

### 示例 3：精确查找
1. 点击"多金属结核"
2. 点击"太平洋"
3. 选择"中国"
4. 地图上只显示中国在太平洋的多金属结核矿区

### 示例 4：取消筛选
1. **矿种/大洋**：再次点击已选中的按钮即可取消
2. **国家**：点击"取消"按钮或选择"-- 全部国家 --"
3. 取消所有筛选后，所有矿区恢复初始状态（白色边框，无高亮）

## 技术实现

### 数据流
```
GeoJSON 加载
  ↓
MapContainer 提取所有国家（sponsor 字段）
  ↓
emit('dataLoaded') → App.vue
  ↓
传递给 LeftPanel (availableCountries)
  ↓
LeftPanel 显示下拉框选项
  ↓
用户选择筛选条件
  ↓
emit('filterChange') → App.vue
  ↓
传递给 MapContainer (filters)
  ↓
MapContainer 应用筛选样式
```

### 关键功能

#### 点击切换（开/关）
```javascript
const toggleMineral = (mineral) => {
    if (activeMineral.value === mineral) {
        activeMineral.value = null; // 再次点击则取消
    } else {
        activeMineral.value = mineral;
    }
};
```

#### 无筛选时恢复初始状态
```javascript
const hasFilter = mineral || ocean || country;
if (!hasFilter) {
    // 恢复初始状态
    entity.polygon.material = entity._originalColor.withAlpha(0.8);
    entity.polygon.outlineColor = Cesium.Color.WHITE.withAlpha(0.9);
    entity.polygon.outlineWidth = 1;
}
```

## 注意事项

1. ✅ 筛选不会隐藏矿区，只是改变透明度和边框
2. ✅ 黄色边框（3px）表示匹配当前筛选条件
3. ✅ 不匹配的矿区半透明显示，便于对比
4. ✅ 国家列表完全基于实际数据，确保准确性
5. ✅ 支持任意组合的联级筛选
6. ✅ 点击切换：再次点击已选中的按钮可以取消筛选
7. ✅ 无筛选时：所有矿区保持初始状态（白色边框，无高亮）
8. ✅ 国家下拉框：方便从众多国家中快速选择
