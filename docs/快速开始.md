# 🚀 快速开始

## 📋 前置要求

- **Node.js** >= 16.0.0
- **npm** >= 7.0.0

检查版本：
```bash
node -v
npm -v
```

## 🛠️ 安装步骤

### 1. 安装依赖

```bash
npm install
```

### 2. 配置环境变量（可选）

如果需要使用 Gemini API，编辑 `.env.local` 文件：

```bash
GEMINI_API_KEY=你的实际API密钥
```

### 3. 启动开发服务器

```bash
npm run dev
```

服务器将在 `http://localhost:3000` 启动。

## 📦 可用命令

| 命令 | 说明 |
|------|------|
| `npm run dev` | 启动开发服务器（热重载） |
| `npm run build` | 构建生产版本到 `dist/` 目录 |
| `npm run preview` | 预览生产构建 |

## 🏗️ 项目结构

```
项目根目录/
├── src/                 # 源代码
│   ├── components/     # Vue 组件

│   ├── main.js         # 入口文件
│   └── constants.js    # 常量
```

详细结构说明请查看 [项目结构说明.md](./项目结构说明.md)

## 🎨 核心功能

### 1. 3D 地球可视化
- 基于 Cesium 实现
- 支持 2D/3D 视图切换
- 集成天地图服务

### 2. 矿区查询系统
- 按矿种类型筛选
- 按大洋区域筛选
- 按国家筛选

### 3. 图层控制
- 环境监测图层
- 灾害预警图层
- 历史数据图层

### 4. 数据展示
- 实时矿区数据表格
- 矿区详情弹窗
- 响应式布局

## 🔧 技术栈

- **Vue 3.5.24** - 前端框架
- **Vite 6.2.0** - 构建工具
- **TypeScript 5.8.2** - 类型支持
- **Cesium 1.114** - 3D 地球
- **Tailwind CSS** - 样式框架
- **天地图** - 地图服务

## 🐛 常见问题

### Q: 启动失败，提示找不到模块？
A: 运行 `npm install` 确保依赖已安装。

### Q: 地图不显示？
A: 检查网络连接，Cesium 和天地图需要联网加载。

### Q: 端口 3000 被占用？
A: 修改 `vite.config.ts` 中的 `server.port` 配置。

### Q: TypeScript 报错？
A: 这些是类型检查警告，不影响运行。
