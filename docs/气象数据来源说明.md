# 气象数据来源说明

## 数据获取方式

所有气象数据都是通过 **船讯网API** 实时获取的，不是本地模拟数据。

## API接口

**接口地址**：
```
https://api.shipxy.com/apicall/v3/GetWeatherByPoint
```

**请求参数**：
- `key`: API密钥（已配置）
- `lng`: 经度（WGS84坐标系）
- `lat`: 纬度（WGS84坐标系）
- `weather_time`: Unix时间戳（秒，可选）- 用于获取未来气象预报

**返回数据**：
```json
{
    "status": 0,
    "data": {
        "windspeed": 12.5,      // 风速 (m/s)
        "winddir": 180,         // 风向 (°)
        "waveheight": 2.3,      // 浪高 (m)
        "swellheight": 1.5,     // 涌浪高 (m)
        "swelldir": 200,        // 涌浪方向 (°)
        "visibility": 10,       // 能见度 (km)
        "temperature": 15,      // 气温 (°C)
        "pressure": 1013        // 气压 (hPa)
    }
}
```

## 调用流程

1. **航线规划完成**后，用户点击"航线气象"按钮
2. **沿航线采样**：每50海里采样一个点
3. **计算到达时间**：根据船速和距离计算每个采样点的预计到达时间
4. **调用API获取气象**：
   ```javascript
   const weatherTime = Math.floor(arrivalTime.getTime() / 1000);
   const result = await getWeatherByPoint(lng, lat, weatherTime);
   ```
5. **数据处理**：计算风险等级（安全/注意/警告/危险）
6. **可视化展示**：
   - 地图上绘制彩色线段
   - 表格显示详细数据

## 数据更新

- **自动刷新**：每5分钟自动刷新一次气象数据
- **手动刷新**：点击"刷新"按钮立即更新
- **实时性**：API返回的是最新的气象预报数据

## 代码位置

**API封装**：`src/utils/shipxyApi.js`
```javascript
export async function getWeatherByPoint(lng, lat, weatherTime = null) {
    let url = `${API_BASE}/GetWeatherByPoint?key=${API_KEY}&lng=${lng}&lat=${lat}`;
    if (weatherTime) url += `&weather_time=${weatherTime}`;
    return await request(url);
}
```

**调用位置**：`src/utils/routeWeatherLayer.js`
```javascript
// 获取气象数据（使用到达时间的Unix时间戳）

```

## 注意事项

1. **API限制**：船讯网API可能有调用频率限制，请合理使用
2. **时间参数**：传入未来时间可获取气象预报，不传则返回当前气象
3. **坐标系统**：使用WGS84坐标系（与GPS一致）
4. **数据精度**：气象数据精度取决于API提供商的数据源
