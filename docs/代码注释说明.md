# 代码注释说明文档

本文档总结了各个组件的函数功能和注释说明。

## 📁 组件结构

```
src/
├── App.vue                 # 主应用组件
├── components/
│   ├── Header.vue          # 顶部栏组件
│   ├── LeftPanel.vue       # 左侧面板组件（矿区查询+图层控制）
│   ├── RightPanel.vue      # 右侧功能按钮组件
│   ├── MapContainer.vue    # 地图容器组件
│   └── BottomTable.vue     # 底部表格组件
└── constants.js            # 常量配置文件

```

---

## 1. App.vue - 主应用组件

### 状态管理
- `currentTab`: 当前选中的顶部选项卡
- `activePanels`: 各个功能面板的显示状态
- `scale`: 屏幕缩放比例（响应式适配）
- `filters`: 筛选条件（矿种、大洋、国家）
- `availableCountries`: 可用的国家列表
- `allMiningData`: 所有矿区数据
- `filteredMiningData`: 过滤后的矿区数据（计算属性）

### 核心函数

#### 响应式适配
- `updateScale()`: 更新屏幕缩放比例
- `containerStyle`: 容器样式（应用缩放变换）

#### 面板切换
- `toggleList()`: 切换矿区列表（底部表格）
- `toggleMapTools()`: 切换地图工具栏
- `toggleQuery()`: 切换矿区查询面板
- `toggleLayers()`: 切换图层控制面板

#### 数据处理
- `handleDataLoaded(data)`: 处理 GeoJSON 数据加载完成事件
- `handleFilterChange(newFilters)`: 处理筛选条件变化事件
- `handleTabChange(tab)`: 处理顶部选项卡切换事件

---

## 2. Header.vue - 顶部栏组件

### 状态管理
- `time`: 当前时间（用于右上角时间显示）
- `activeTab`: 当前激活的选项卡
- `leftTabs`: 左侧选项卡列表
- `rightTabs`: 右侧选项卡列表

### 核心函数

#### 事件处理
- `selectTab(tab)`: 选择选项卡，更新状态并发送事件

#### 工具函数
- `formatDate(date)`: 格式化日期（YYYY/MM/DD）
- `formatTime(date)`: 格式化时间（HH:MM）

---

## 3. LeftPanel.vue - 左侧面板组件

### 状态管理
- `activeMinerals`: 选中的矿种列表（多选）
- `activeOceans`: 选中的大洋列表（多选）
- `activeCountries`: 选中的国家列表（多选）
- `currentCountries`: 当前可用的国家列表
- `layers`: 图层数据（用于图层控制面板）
- `showCountryPanel`: 国家面板的展开/收起状态

### 核心函数

#### 筛选功能
- `emitFilter()`: 发送筛选条件变化事件
- `toggleMineral(mineral)`: 切换矿种选择状态（多选）
- `toggleOcean(ocean)`: 切换大洋选择状态（多选）
- `toggleCountry(country)`: 切换国家选择状态（多选）
- `removeCountry(country)`: 移除单个国家
- `clearCountries()`: 清除所有国家筛选

#### 面板控制
- `toggleCountryPanel()`: 切换国家面板的展开/收起状态

#### 图层控制
- `toggleLayer(parentId, layerId)`: 切换图层的显示状态

---

## 4. RightPanel.vue - 右侧功能按钮组件

### 计算属性
- `currentTools`: 根据当前选项卡动态获取功能列表

### 核心函数

#### 事件处理
- `handleToggle(tool)`: 处理功能按钮点击事件
  - 通用功能：地图工具（所有选项卡可用）
  - 专属功能：矿区列表、矿区查询、图层控制（仅"一图一表"可用）
  - 未实现功能：显示"功能开发中"提示

#### 状态判断
- `isActive(tool)`: 判断功能按钮是否处于激活状态

---

## 5. MapContainer.vue - 地图容器组件

### 核心功能
- Cesium 地图初始化
- GeoJSON 数据加载和渲染
- 矿区点击交互
- 信息面板显示
- 地图工具栏（放大、缩小、复位、2D/3D切换、全屏）
- 筛选功能（矿种、大洋、国家）
- 鹰眼地图（开发中）

### 主要函数
- `initCesium()`: 初始化 Cesium 地图
- `loadMiningData()`: 加载海洋采矿数据
- `closeInfo()`: 关闭信息面板
- `zoomIn()`: 放大地图
- `zoomOut()`: 缩小地图
- `resetView()`: 复位视角
- `toggle2D3D()`: 2D/3D 切换
- `toggleFullscreen()`: 全屏切换
- `applyFilters()`: 应用筛选条件

---

## 6. constants.js - 常量配置文件

### 配置项
- `APP_TITLE`: 应用标题
- `MINERAL_TYPES`: 矿种类型列表
- `OCEANS`: 大洋区域列表
- `COUNTRY_MAPPING`: 国家映射（基于大洋）
- `RIGHT_TOOLS`: 右侧功能按钮列表
- `TAB_TOOLS_MAPPING`: 选项卡与功能的映射关系

### 工具函数
- `getLayersByOcean(oceanName)`: 根据大洋动态生成图层数据

---

## 🔄 数据流向

```
1. GeoJSON 数据加载
   MapContainer.vue (loadMiningData)
   ↓
   App.vue (handleDataLoaded)
   ↓
   LeftPanel.vue (availableCountries)

2. 筛选条件变化
   LeftPanel.vue (toggleMineral/toggleOcean/toggleCountry)
   ↓
   LeftPanel.vue (emitFilter)
   ↓
   App.vue (handleFilterChange)
   ↓
   MapContainer.vue (applyFilters)

3. 选项卡切换
   Header.vue (selectTab)
   ↓
   App.vue (handleTabChange)
   ↓
   RightPanel.vue (currentTools)
```

## 📝 注释规范

所有函数都遵循以下注释规范：

```javascript
/**
 * 函数功能描述
 * @param {Type} paramName - 参数说明
 * @returns {Type} 返回值说明
 * 
 * 功能：
 * 1. 功能点1
 * 2. 功能点2
 * 3. 功能点3
 */
```

## 🎯 关键特性

1. **响应式适配**: 使用 CSS transform: scale() 实现全屏适配
2. **多选筛选**: 支持矿种、大洋、国家的多选筛选
3. **选项卡联动**: 顶部选项卡与右侧功能按钮联动
4. **实时更新**: 筛选条件变化时，地图和表格实时更新
5. **科技风格**: 赛博朋克风格的 UI 设计

## 📚 扩展指南

### 添加新的选项卡功能

1. 在 `constants.js` 中的 `TAB_TOOLS_MAPPING` 添加映射
2. 在 `RightPanel.vue` 的 `handleToggle` 函数中添加处理逻辑
3. 在 `App.vue` 中添加对应的状态和函数

### 添加新的筛选条件

1. 在 `LeftPanel.vue` 中添加状态和切换函数
2. 在 `emitFilter` 函数中包含新的筛选条件
3. 在 `MapContainer.vue` 的 `applyFilters` 函数中添加筛选逻辑
4. 在 `App.vue` 的 `filteredMiningData` 中添加过滤逻辑
