# 国家折叠面板功能说明

## 功能概述

国家筛选使用可折叠面板设计，点击箭头展开/收起国家选择区域，已选中的国家以标签形式始终显示在标题下方。

## UI 布局

### 收起状态
```
┌─────────────────────────────────────┐
│ ● 所属国家 (已选 3)    ▼    [清空] │
├─────────────────────────────────────┤
│ [中国 ✕] [日本 ✕] [俄罗斯 ✕]       │
└─────────────────────────────────────┘
```

### 展开状态
```
┌─────────────────────────────────────┐
│ ● 所属国家 (已选 3)    ▲    [清空] │
├─────────────────────────────────────┤
│ [中国 ✕] [日本 ✕] [俄罗斯 ✕]       │
├─────────────────────────────────────┤
│ ┌─────────────────────────────────┐ │
│ │ [中国] [日本] [俄罗斯] [韩国]   │ │
│ │ [印度] [法国] [德国] [美国]     │ │
│ │ [波兰] ...                      │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

## 操作方式

### 1. 展开/收起面板
- 点击标题栏右侧的 **▼** 箭头展开国家选择面板
- 点击 **▲** 箭头收起面板
- 箭头会旋转 180° 提示当前状态

### 2. 选择国家
- 展开面板后，点击任意国家按钮
- 选中的国家会：
  - 在面板中变为黄色高亮
  - 在标题下方显示为黄色标签
  - 地图上对应国家的矿区被高亮

### 3. 取消选择
- **方式 1**：在展开的面板中，再次点击已选中的国家按钮
- **方式 2**：点击标签上的 ✕ 按钮移除单个国家
- **方式 3**：点击"清空"按钮移除所有国家

### 4. 查看已选
- 已选国家始终以黄色标签形式显示在标题下方
- 标题旁显示已选数量：`(已选 3)`
- 无需展开面板即可查看和管理已选国家

## 视觉效果

### 标题栏
- 青色圆点 + "所属国家" 文字
- 已选数量：黄色文字 `(已选 3)`
- 箭头按钮：悬停时变浅色，展开时旋转 180°
- 清空按钮：红色背景，仅在有选中项时显示

### 已选标签
- 背景：黄色 `bg-yellow-500`
- 文字：黑色粗体
- 发光效果：`shadow-[0_0_8px_rgba(250,204,21,0.4)]`
- 移除按钮：✕ 符号，悬停时变红色

### 选择面板
- 背景：深色半透明 `bg-slate-900/50`
- 边框：灰色 `border-slate-700/30`
- 最大高度：200px，超出时滚动
- 按钮：未选中为灰色，选中为黄色高亮

### 折叠动画
- 展开/收起：平滑的高度和透明度过渡
- 持续时间：0.3 秒
- 缓动函数：ease

## 使用示例

### 示例 1：选择单个国家
1. 点击箭头 ▼ 展开面板
2. 点击"中国"按钮
3. "中国"按钮变为黄色
4. 标题下方出现黄色标签：`[中国 ✕]`
5. 地图上中国的矿区被高亮
6. 可以点击箭头 ▲ 收起面板

### 示例 2：选择多个国家
1. 展开面板
2. 依次点击"中国"、"日本"、"俄罗斯"
3. 三个按钮都变为黄色
4. 标题下方显示三个标签
5. 标题显示 `(已选 3)`
6. 地图上这三个国家的矿区都被高亮

### 示例 3：在面板中取消选择
1. 展开面板
2. 再次点击已选中的"日本"按钮
3. "日本"按钮恢复灰色
4. 标签区域的"日本"标签消失
5. 地图上日本的矿区不再高亮

### 示例 4：通过标签移除
1. 不需要展开面板
2. 直接点击标签上的 ✕ 按钮
3. 标签消失
4. 如果面板是展开状态，对应按钮也会恢复灰色

### 示例 5：清空所有国家
1. 点击"清空"按钮
2. 所有标签消失
3. 如果面板是展开状态，所有按钮恢复灰色
4. 地图恢复到只按矿种和大洋筛选的状态

## 技术实现

### 折叠面板状态
```javascript
const showCountryPanel = ref(false);

const toggleCountryPanel = () => {
    showCountryPanel.value = !showCountryPanel.value;
};
```

### 折叠动画
```vue
<transition name="slide-down">
    <div v-if="showCountryPanel">
        <!-- 国家选择面板 -->
    </div>
</transition>
```

```css
.slide-down-enter-active,
.slide-down-leave-active {
    transition: all 0.3s ease;
    max-height: 200px;
    overflow: hidden;
}

.slide-down-enter-from,
.slide-down-leave-to {
    max-height: 0;
    opacity: 0;
}
```

### 箭头旋转
```vue
<svg 
    class="w-5 h-5 transition-transform duration-300" 
    :class="{ 'rotate-180': showCountryPanel }"
>
    <path d="M19 9l-7 7-7-7"/>
</svg>
```

### 双向同步
```javascript
// 在面板中点击按钮
const toggleCountry = (country) => {
    const index = activeCountries.value.indexOf(country);
    if (index > -1) {
        activeCountries.value.splice(index, 1); // 移除
    } else {
        activeCountries.value.push(country); // 添加
    }
    emitFilter();
};

// 点击标签上的 ✕
const removeCountry = (country) => {
    const index = activeCountries.value.indexOf(country);
    if (index > -1) {
        activeCountries.value.splice(index, 1);
        emitFilter();
    }
};
```

## 优势

### 1. 节省空间
- 默认收起状态，不占用额外空间
- 只在需要时展开选择面板
- 已选标签始终可见，方便管理

### 2. 操作灵活
- 可以在面板中选择/取消
- 可以通过标签快速移除
- 可以通过"清空"批量清除

### 3. 状态清晰
- 箭头方向提示面板状态
- 已选数量一目了然
- 标签和面板按钮状态同步

### 4. 体验流畅
- 平滑的展开/收起动画
- 箭头旋转动画
- 按钮悬停效果
