## 添加新组件

### 1. 创建组件文件

在 `src/components/` 目录下创建新的 `.vue` 文件：

```vue
<!-- src/components/MyComponent.vue -->
<template>
  <div class="my-component">
    <h2>{{ title }}</h2>
    <button @click="handleClick">点击我</button>
  </div>
</template>

<script>
import { ref } from 'vue';

export default {
  name: 'MyComponent',
  props: {
    title: {
      type: String,
      default: '默认标题'
    }
  },
  setup(props) {
    const handleClick = () => {
      console.log('按钮被点击了！');
    };

    return {
      handleClick
    };
  }
};
</script>

<style scoped>
.my-component {
  padding: 20px;
}
</style>
```

### 2. 在父组件中使用

```vue
<template>
  <div>
    <MyComponent title="我的标题" />
  </div>
</template>

<script>
import MyComponent from '@/components/MyComponent.vue';

export default {
  components: {
    MyComponent
  }
};
</script>
```

## 使用环境变量

### 1. 定义环境变量

在 `.env` 文件中定义（必须以 `VITE_` 开头）：

```bash
VITE_APP_TITLE=我的应用
VITE_API_BASE_URL=https://api.example.com
```

### 2. 在代码中使用

```javascript
// 获取环境变量
const appTitle = import.meta.env.VITE_APP_TITLE;
const apiUrl = import.meta.env.VITE_API_BASE_URL;

console.log(appTitle); // 输出: 我的应用
```

### 3. 不同环境的配置

- `.env` - 所有环境通用
- `.env.development` - 开发环境
- `.env.production` - 生产环境
- `.env.local` - 本地环境（不提交到 Git）

## 路径别名

### 配置说明

在 `vite.config.ts` 中已配置 `@` 别名指向 `src` 目录：

```typescript
resolve: {
  alias: {
    '@': path.resolve(__dirname, './src'),
  }
}
```

### 使用示例

```javascript
// ❌ 不推荐：相对路径
import MyComponent from '../../../components/MyComponent.vue';

// ✅ 推荐：使用别名
import MyComponent from '@/components/MyComponent.vue';
import { MY_CONSTANT } from '@/constants.js';
```

## 代码规范

### 组件命名

```javascript
// ✅ 推荐：PascalCase
MyComponent.vue
UserProfile.vue
DataTable.vue

// ❌ 不推荐
mycomponent.vue
user-profile.vue
```

### 变量命名

```javascript
// ✅ 推荐：camelCase
const userName = 'John';
const isActive = true;

// ❌ 不推荐
const user_name = 'John';
const IsActive = true;
```

### 常量命名

```javascript
// ✅ 推荐：UPPER_SNAKE_CASE
const API_BASE_URL = 'https://api.example.com';
const MAX_RETRY_COUNT = 3;
```

### 组件结构

```vue
<template>
  <!-- 模板内容 -->
</template>

<script>
// 1. 导入
import { ref, computed } from 'vue';

// 2. 组件定义
export default {
  name: 'ComponentName',
  
  // 3. Props
  props: {
    // ...
  },
  
  // 4. Setup
  setup() {
    // ...
  }
};
</script>

<style scoped>
/* 样式 */
</style>
```

## 调试技巧

### 1. 使用 Vue DevTools

安装 Vue DevTools 浏览器扩展，可以：
- 查看组件树
- 检查组件状态
- 追踪事件
- 性能分析

### 2. Console 调试

```javascript
// 在 setup 中
setup() {
  const count = ref(0);
  
  // 调试输出
  console.log('count:', count.value);
  
  // 监听变化
  watch(count, (newVal) => {
    console.log('count changed:', newVal);
  });
  
  return { count };
}
```

### 3. 断点调试

在浏览器开发者工具中：
1. 打开 Sources 面板
2. 找到对应的文件
3. 点击行号设置断点
4. 刷新页面触发断点

### 4. 网络请求调试

```javascript
// 使用 fetch
fetch(url)
  .then(res => {
    console.log('Response:', res);
    return res.json();
  })
  .then(data => {
    console.log('Data:', data);
  })
  .catch(err => {
    console.error('Error:', err);
  });
```

## 常用 Vue 3 API

### Composition API

```javascript
import { 
  ref,           // 响应式引用
  reactive,      // 响应式对象
  computed,      // 计算属性
  watch,         // 监听器
  onMounted,     // 挂载钩子
  onUnmounted    // 卸载钩子
} from 'vue';

export default {
  setup() {
    // 响应式数据
    const count = ref(0);
    const state = reactive({ name: 'John' });
    
    // 计算属性
    const double = computed(() => count.value * 2);
    
    // 监听器
    watch(count, (newVal, oldVal) => {
      console.log(`count changed from ${oldVal} to ${newVal}`);
    });
    
    // 生命周期
    onMounted(() => {
      console.log('组件已挂载');
    });
    
    onUnmounted(() => {
      console.log('组件已卸载');
    });
    
    return {
      count,
      state,
      double
    };
  }
};
```

## 性能优化

### 1. 使用 v-show vs v-if

```vue
<!-- 频繁切换使用 v-show -->
<div v-show="isVisible">内容</div>

<!-- 条件很少改变使用 v-if -->
<div v-if="isLoggedIn">用户信息</div>
```

### 2. 列表渲染使用 key

```vue
<div v-for="item in items" :key="item.id">
  {{ item.name }}
</div>
```

### 3. 计算属性缓存

```javascript
// ✅ 推荐：使用计算属性（有缓存）
const filteredList = computed(() => {
  return list.value.filter(item => item.active);
});

// ❌ 不推荐：使用方法（每次都计算）
const getFilteredList = () => {
  return list.value.filter(item => item.active);
};
```
