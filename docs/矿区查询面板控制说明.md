# 矿区查询面板控制说明

## 功能概述

右侧栏的"专题统计"已改为"矿区查询"，点击可以控制左侧栏中矿区查询分类面板的显示和隐藏。

## 修改内容

### 1. 右侧栏按钮名称修改
- **旧名称**：专题统计
- **新名称**：矿区查询
- **功能**：控制左侧矿区查询分类面板的显隐

### 2. 面板状态管理
```javascript
activePanels = {
    list: false,      // 矿区列表
    mapTools: false,  // 地图工具
    query: true       // 矿区查询（默认显示）
}
```

### 3. 左侧面板显隐控制
- 矿区查询分类面板使用 `v-if` 控制显隐
- 添加 `slide-down` 过渡动画
- 图层控制面板始终显示

## 操作方式

### 显示/隐藏矿区查询面板
1. 点击右侧栏的"矿区查询"按钮
2. 左侧的矿区查询分类面板会显示/隐藏
3. 按钮状态会相应变化（黄色边框表示已打开）

### 多面板同时打开
可以同时打开多个面板：
- ✅ 矿区查询 + 矿区列表
- ✅ 矿区查询 + 地图工具
- ✅ 矿区列表 + 地图工具
- ✅ 矿区查询 + 矿区列表 + 地图工具

## 视觉效果

### 矿区查询按钮
- **未打开**：
  - 灰色背景
  - 青色边框
  - 悬停时向左移动 6px
  
- **已打开**：
  - 青色渐变背景
  - 黄色边框
  - 向左移动 10px
  - 发光效果

### 矿区查询面板
- **显示动画**：从上到下滑入，透明度从 0 到 1
- **隐藏动画**：从下到上滑出，透明度从 1 到 0
- **动画时长**：0.3 秒

## 默认状态

### 页面加载时
- ✅ 矿区查询面板：**显示**（默认打开）
- ❌ 矿区列表：隐藏
- ❌ 地图工具：隐藏

### 原因
矿区查询是核心功能，默认显示方便用户立即使用筛选功能。

## 技术实现

### 右侧栏按钮判断
```javascript
const isActive = (tool) => {
    if (tool === '矿区列表') return props.activePanels.list;
    if (tool === '地图工具') return props.activePanels.mapTools;
    if (tool === '矿区查询') return props.activePanels.query;
    return false;
};
```

### 左侧面板显隐
```vue
<transition name="slide-down">
    <div v-if="showQueryPanel" class="tech-panel-enhanced ...">
        <!-- 矿区查询分类面板内容 -->
    </div>
</transition>
```

### 状态切换
```javascript
const toggleQuery = () => {
    activePanels.value.query = !activePanels.value.query;
};
```

## 使用场景

### 场景 1：隐藏查询面板，专注查看地图
1. 点击"矿区查询"按钮关闭面板
2. 左侧只显示图层控制面板
3. 地图区域更宽阔

### 场景 2：同时使用查询和列表
1. 保持"矿区查询"面板打开
2. 点击"矿区列表"按钮
3. 可以在左侧筛选，在底部查看列表

### 场景 3：完整功能使用
1. 打开"矿区查询"面板
2. 打开"地图工具"
3. 打开"矿区列表"
4. 同时使用筛选、工具和列表功能

## 注意事项

1. ✅ 矿区查询面板默认显示
2. ✅ 图层控制面板始终显示，不受控制
3. ✅ 支持多个面板同时打开
4. ✅ 平滑的显示/隐藏动画
5. ✅ 按钮状态实时反映面板状态
6. ✅ 关闭查询面板不影响已设置的筛选条件

## 面板层级关系

```
左侧栏
├── 矿区查询分类面板（可控制显隐）
│   ├── 矿种类型
│   ├── 所属大洋
│   └── 所属国家
└── 图层控制面板（始终显示）
    ├── 环境监测
    ├── 灾害预警
    └── 历史整编数据

右侧栏
├── 地图工具（控制地图工具栏）
├── 矿区查询（控制左侧查询面板）✨ 新增
├── 矿区列表（控制底部列表）
├── 矿区情况
├── 预报中心
├── 图件导出
└── 意见反馈
```
