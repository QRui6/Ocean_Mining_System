# 🚀 风场图层快速上手

## 5 分钟快速开始

### 第 1 步：启动项目

```bash
npm run dev
```

### 第 2 步：打开浏览器

访问控制台显示的地址（通常是 `http://localhost:5173`）

### 第 3 步：找到风场按钮

在地图右侧工具栏，从上到下依次是：
1. 🔍 放大
2. 🔍 缩小
3. 🏠 复位视角
4. 🔄 2D/3D 切换
5. ⛶ 全屏
6. **➡️ 风场** ← 这个就是！

### 第 4 步：点击显示风场

点击风场按钮，等待 1-2 秒，你会看到：
- ✨ 流动的粒子动画
- 🎨 颜色从青色到红色渐变
- 🟢 按钮右上角出现绿色指示灯

### 第 5 步：观察风场效果

**太平洋区域风场特点**：
- **北部**（30°N 以上）：强西风，粒子快速向东移动，颜色偏黄/橙
- **中部**（5°N-30°N）：信风带，粒子向西移动，颜色偏绿
- **赤道**（-5°N-5°N）：无风带，粒子缓慢移动，颜色偏青
- **南部**（-30°S 以下）：强西风，粒子快速向东移动，颜色偏黄/橙

## 🎮 交互操作

### 显示/隐藏风场
- 点击风场按钮切换显示状态
- 绿色指示灯表示风场正在显示

### 与地图交互
- 风场显示时，仍可正常操作地图（缩放、旋转、平移）
- 可以同时查看矿区和风场
- 点击矿区仍能弹出信息面板

### 2D/3D 切换
- 风场在 2D 和 3D 模式下都能正常显示
- 切换模式时风场会保持显示状态

## 🎨 颜色含义

风场粒子的颜色表示风速：

| 颜色 | 风速范围 | 说明 |
|------|---------|------|
| 🔵 青色 | 0-5 m/s | 微风 |
| 🟢 绿色 | 5-10 m/s | 轻风 |
| 🟡 黄色 | 10-15 m/s | 和风 |
| 🟠 橙色 | 15-20 m/s | 强风 |
| 🔴 红色 | >20 m/s | 大风 |

## 🔧 常见调整

### 想要更多粒子？
编辑 `src/components/MapContainer.vue`，找到 `initWindLayer` 函数：
```javascript
particlesTextureSize: 256,  // 从 128 改为 256
```

### 想要更快的风速？
```javascript
speedFactor: 1.5,  // 从 0.8 改为 1.5
```

### 想要更粗的线条？
```javascript
lineWidth: 5.0,  // 从 3.0 改为 5.0
```

## 🐛 遇到问题？

### 风场不显示
1. 按 F12 打开开发者工具
2. 查看 Console 标签页
3. 寻找错误信息（红色文字）
4. 参考 `docs/wind-layer-test.md` 进行排查

### 性能卡顿
1. 降低粒子密度：`particlesTextureSize: 64`
2. 降低帧率：`frameRate: 15`
3. 关闭其他浏览器标签页

### 颜色看不清
1. 增加线宽：`lineWidth: 5.0`
2. 使用更鲜艳的颜色：
   ```javascript
   colors: ['#0000ff', '#00ff00', '#ffff00', '#ff0000']
   ```
