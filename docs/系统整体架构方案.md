## 三、数据流设计

### 3.1 矿区数据流（静态）

```
GeoJSON 文件
    ↓ 一次性加载
前端 Cesium
    ↓ 用户筛选
实时渲染
```

**特点**：
- 数据量：1401 条
- 更新频率：低（月/年）
- 无需后端

### 3.2 气象数据流（定时）

```
NOAA / OpenWeatherMap
    ↓ 每 6 小时
后端定时任务
    ↓ 格式转换 + 压缩
Redis 缓存
    ↓ HTTP API
前端 Cesium
    ↓ 粒子系统
实时渲染
```

**特点**：
- 数据量：5 MB → 500 KB (压缩)
- 更新频率：6 小时
- 需要后端

### 3.3 AIS 数据流（实时）

```
MarineTraffic API
    ↓ 每 10 秒
后端 AIS 服务
    ↓ 数据处理
Redis 缓存 + PostgreSQL 存储
    ↓ WebSocket 推送
前端 Cesium
    ↓ 实体更新
实时渲染
```

**特点**：
- 数据量：100-1000 船舶
- 更新频率：10 秒
- 必须后端 + WebSocket

## 四、性能优化策略

### 4.1 前端优化

#### 分层渲染
```javascript
// 根据相机高度动态调整细节
const height = viewer.camera.positionCartographic.height;

if (height > 20000000) {
  // 远距离：低细节
  showMiningAreas();      // 只显示矿区
  hideVessels();          // 隐藏船舶
  hideWeatherParticles(); // 隐藏气象
} else if (height > 5000000) {
  // 中距离：中等细节
  showMiningAreas();
  showVesselClusters();   // 显示船舶聚类
  showWeatherParticles(3000); // 3000 粒子
} else {
  // 近距离：高细节
  showMiningAreas();
  showAllVessels();       // 显示所有船舶
  showWeatherParticles(5000); // 5000 粒子
}
```

#### 按需加载
```javascript
// 只加载可见区域的数据
const bounds = viewer.camera.computeViewRectangle();

// 加载该区域的船舶
loadVesselsInBounds(bounds);

// 加载该区域的气象数据
loadWeatherInBounds(bounds);
```

#### 数据缓存
```javascript
// 前端缓存策略
const cache = new Map();

async function fetchVessels(bounds) {
  const key = JSON.stringify(bounds);
  
  // 检查缓存（30 秒有效）
  if (cache.has(key)) {
    const { data, timestamp } = cache.get(key);
    if (Date.now() - timestamp < 30000) {
      return data;
    }
  }
  
  // 从服务器获取
  const data = await api.getVessels(bounds);
  cache.set(key, { data, timestamp: Date.now() });
  
  return data;
}
```

### 4.2 后端优化

#### 数据缓存
```javascript
// Redis 缓存策略
class CacheService {
  // 矿区数据：缓存 1 天
  static async getMiningAreas() {
    return await redis.get('mining:areas', () => {
      return db.query('SELECT * FROM mining_areas');
    }, 86400);
  }
  
  // 气象数据：缓存 6 小时
  static async getWeatherData(bounds) {
    const key = `weather:${JSON.stringify(bounds)}`;
    return await redis.get(key, () => {
      return weatherAPI.fetch(bounds);
    }, 21600);
  }
  
  // AIS 数据：缓存 30 秒
  static async getVessels(bounds) {
    const key = `vessels:${JSON.stringify(bounds)}`;
    return await redis.get(key, () => {
      return aisAPI.fetch(bounds);
    }, 30);
  }
}
```

#### 数据库优化

-- 为船舶位置创建空间索引
