# 气象数据问题说明与解决方案

## 问题描述

在使用船讯网API的 `weather_time` 参数获取未来气象预报时，发现返回的数据中部分字段显示为负数（如 `-32767.0`），这是无效数据。

## 问题原因

根据API文档和测试结果：

1. **API返回的特殊值**：`-32767` 是API用来表示"无数据"或"不适用"的特殊标记
2. **未来预报数据不稳定**：API的 `weather_time` 参数虽然存在，但返回的未来预报数据质量不稳定
3. **部分字段不支持预报**：某些气象字段（如 `bm500`）在未来时间可能没有预报数据

## 解决方案

### 方案1：使用当前气象数据（已实施）

**优点**：
- 数据稳定可靠
- 所有字段都有有效值
- 适合短期航线（几小时到1-2天）

**缺点**：
- 无法获取未来气象预报
- 对长期航线（3天以上）参考价值有限

**实现**：
```javascript
// 所有采样点都使用当前时间的气象数据
const result = await getWeatherByPoint(point.lng, point.lat);
```

### 方案2：数据清理（已实施）

添加数据清理函数，过滤无效值：

```javascript
cleanWeatherData(data) {
    const cleaned = { ...data };
    
    // -32767 是API返回的"无数据"标记，将其替换为0
    Object.keys(cleaned).forEach(key => {
        if (typeof cleaned[key] === 'number' && cleaned[key] < -30000) {
            cleaned[key] = 0;
        }
    });
    
    return cleaned;
}
```

### 方案3：混合策略（推荐，待实施）

- **第一个点**：使用当前时间（起点）
- **2-24小时内的点**：使用当前气象数据（短期内变化不大）
- **24小时后的点**：尝试使用未来预报，如果数据无效则使用当前数据

```javascript
if (index === 0 || point.hoursFromStart < 24) {
    // 使用当前气象
    result = await getWeatherByPoint(point.lng, point.lat);
} else {
    // 尝试使用未来预报
    const weatherTime = Math.floor(point.arrivalTime.getTime() / 1000);
    result = await getWeatherByPoint(point.lng, point.lat, weatherTime);
    
    // 如果数据无效，回退到当前气象
    if (hasInvalidData(result.data)) {
        result = await getWeatherByPoint(point.lng, point.lat);
    }
}
```

## 当前实现

目前采用**方案1 + 方案2**的组合：

1. 所有采样点都使用当前时间的气象数据
2. 对返回的数据进行清理，过滤 `-32767` 等无效值
3. 表格中显示预计到达时间，但气象数据是当前时刻的

## 数据说明

### 有效数据示例
```json
{
    "windspeed": 9.4,      // 风速 (m/s)
    "winddir": 45.3,       // 风向 (°)
    "waveheight": 2.7,     // 浪高 (m)
    "temperature": 19.3,   // 气温 (°C)
    "pressure": 1020.6     // 气压 (hPa)
}
```

### 无效数据示例
```json
{
    "bm500": -32767.0,     // 无效值
    "oceandir": -32767.0,  // 无效值
    "windspeed": 9.4,      // 有效值
    "waveheight": 2.7      // 有效值
}
```

## 建议

### 短期航线（< 24小时）
- 使用当前气象数据即可
- 气象变化不大，参考价值高

### 中期航线（1-3天）
- 可以尝试使用未来预报
- 需要验证数据有效性
- 建议每6-12小时刷新一次

### 长期航线（> 3天）
- 建议分段规划
- 每天更新气象数据
- 或接入其他气象预报服务

## 未来优化方向

1. **接入多个气象数据源**：
   - 船讯网API（当前气象）
   - 其他专业气象服务（未来预报）
   - 融合多源数据提高准确性

2. **智能数据验证**：
   - 检测异常值
   - 数据平滑处理
   - 缺失值插值

3. **预报准确度评估**：
   - 记录预报数据
   - 对比实际气象
   - 评估预报准确率

## 总结

目前的实现方案能够保证数据的稳定性和可靠性，适合短期航线的气象分析。对于长期航线，建议：

1. 使用当前气象数据作为参考
2. 定期刷新数据（每6-12小时）
3. 结合其他气象预报服务
4. 分段规划，动态调整
