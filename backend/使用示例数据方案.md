# 使用示例数据方案

## 问题说明

NOAA NOMADS 服务器从中国大陆无法直接访问（被防火墙阻断）。

错误：`Client network socket disconnected before secure TLS connection was established`

---

## 🎯 推荐方案：使用示例数据

我们可以使用项目中已有的风场数据作为示例，展示功能。

### 方案一：使用现有的风场数据

你的项目中已经有这些数据文件：
- `public/data/wind_data_0701.json` - 全球风场数据
- `public/data/wind-sample.json` - 示例风场数据
- `public/data/wind_timeline_optimized/` - 时序风场数据

这些数据可以直接用于演示！

## 🌐 替代方案：使用国内气象数据源

### 选项 1：中国气象局数据

- **网站**: http://data.cma.cn/
- **优点**: 国内访问快速
- **缺点**: 需要注册申请

### 选项 2：OpenWeatherMap

- **网站**: https://openweathermap.org/
- **优点**: 免费 API，全球可访问
- **缺点**: 数据格式不同，需要转换

### 选项 3：使用代理访问 NOAA

如果你有代理服务器，可以配置 axios 使用代理：

```javascript
const response = await axios({
    method: 'GET',
    url: url,
    responseType: 'arraybuffer',
    timeout: 60000,
    proxy: {
        host: 'your-proxy-host',
        port: 1080,
        protocol: 'http'
    }
});
```
