# Project Instructions

- Before adding or changing frontend panels, buttons, cards, dialogs, tool workspaces, or right-side menu interactions, read `UI_PANEL_STYLE_GUIDE.md`.
- New module styles must follow the mining overview "矿区查询" panel style.
- Reuse existing shared classes where applicable: `tech-panel-enhanced`, `corner-decoration`, `custom-scrollbar`, and `floating-panel-close-btn`.
- Do not casually change existing module styles. If new styles are needed, scope them to the new module or reuse existing shared classes.
- Right-side menu show/hide behavior must follow the logic described in `UI_PANEL_STYLE_GUIDE.md`.
